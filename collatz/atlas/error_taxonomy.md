# 错误分类库（种子版，0.3 校准前由 orchestrator 起草；校准后按实际找到的错误修订）

每类给出：特征、典型说法、对照映射上的检验。Critic CRITERION 逐类排查。
标签说明：本文件的分类是 HEURISTIC，用于审查清单，不是任何定理的前提。

| id | 类别 | 特征 | 检验 |
|---|---|---|---|
| E01 | 平均当全称 | 由“平均每步乘 3/4”“概率趋于 0”“密度为 1”推出对所有 n | 结论里有没有“几乎所有/密度/期望”；把同一推理用于 5n+1（平均增长） |
| E02 | 循环论证 | 某一步假设轨道终将落到某个已知集合、或假设没有发散轨道、没有非平凡圈 | 找出该步的前提，它是否等价于原猜想 |
| E03 | 强归纳偷换 | “假设所有 k < n 成立，n 的轨道会降到 n 以下”——后半句正是要证的停时有限 | 停时有限对每个 n 是否被单独证明了 |
| E04 | 逆向树覆盖不完全 | 构造逆向树，证明每层非空、无穷、或各剩余类都出现，就说覆盖全部正整数 | 同样的构造在 3n−1 的逆向树（以 1 为根）上是否也“成立”；3n−1 有不在该树里的圈 |
| E05 | 有限模式推到无限 | 每个有限奇偶向量都出现 ⇒ 关于无限轨道的结论 | 有限前缀与无限序列之间有没有紧性或一致性论证 |
| E06 | 剩余类不一致 | 对每个 k 证明了 mod 2^k 的某类下降，但下降所需步数或 k 依赖于 n、没有一致上界 | 是否有一个对全部 n 成立的有限覆盖 |
| E07 | 忽略圈或只证一半 | 只证不发散（或只证无圈）就宣称猜想成立 | 结论是否同时排除了非平凡圈和发散轨道 |
| E08 | 对照映射同样适用 | 证明中所有用到的性质在 3n−1、5n+1 或负整数上同样成立 | 逐步代入对照映射，看哪一步首先失效；没有一步失效就是错的 |
| E09 | 算术或不等式错误 | 符号、方向、取整、整除性写错 | 用精确整数小例子代入 |
| E10 | 极限与连续性滥用 | 在 ℤ₂、ℝ 或测度空间里取极限后搬回 ℕ；共轭映射的连续性推出有理点性质 | 那个性质对 ℤ₂ 里的非整数点是否也被“证明”了 |
| E11 | 定义或命题偷换 | 映射写错，漏掉 n > 0，结论换成“存在 n”或加了空真假设 | 把证明的命题与原命题逐字比较 |
| E12 | 未证明的断言 | “显然”“易见”“可以证明”之后没有论证，而该步恰是难点 | 该步若成立，是否已经蕴含猜想 |
| E13 | 无穷集上的鸽巢或计数 | 两个无穷集“一样多”或“一个更多”推出包含关系 | 有限截断后计数是否还成立 |
| E14 | 形式化层面的空洞 | Lean 命题多余假设、空真量词、局部重定义、依赖未登记公理 | 交给 verify.sh 和 REPRODUCE |
