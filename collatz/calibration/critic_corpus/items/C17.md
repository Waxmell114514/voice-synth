## Claim

Theorem 5.1. For a given natural number x the 3x + 1-procedure on x, ter-
minates on 1.


## Definitions used

1. Notation
We use standard notation. N denotes the set of all natural numbers, elements
of the set N are denoted by x, y, z etc. For a given natural number x by
3x + 1-procedure for x we understand a sequence of numbers (x, x1 , ..., xm , ...)
starting from x = x0 and such that for a given xn we put xn+1 = 3x + 1 if
xm is odd, and xn+1 = 12 xn if xn is an even number. We prove that for any
given x ∈ N the 3x + 1-procedure for x terminates at 1.


## Proof

2. Useful lemmas
First we notice an obvious:
Lemma 2.1. For a given natural number x, the 3x + 1-procedure for x ter-
minates at 1 if and only if it terminates for the number y = 2n · x for any
natural n.
      Proof
      Assume that the 3x + 1 procedure terminates for x. Then in this proce-
dure for y we first divide by 2n and then do the 3x + 1-procedure and finish it
at 1. And vice versa, if the 3x + 1 procedure for y finishes at 1, it is obvious,
that by the way (after dividing y first by 2n ) we do this procedure for x,
finishing at 1. Therefore the Lemma 2.1 holds. 
Lemma 2.2. If in the 3x + 1-procedure for a natural number x there is a
number y < x then the 3x + 1-procedure x terminates at 1.

     Proof
     Assume that for a natural number x we obtain a number y < x in the
3x + 1-procedure for x. We proceed by induction and show that then for x
the 3x + 1-procedure terminates at 1.
For x = 1 there is nothing to prove.
We consider x = 2. Then in the 3x + 1-procedure for x we get y = 1 < x.
Assume that the 3x + 1-procedure terminates at 1 for every y < x. Consider
the 3x + 1-procedure for x. By the assumption of lemma we get that the
procedure for y terminates at 1. Consequently the 3x + 1 procedure on y we
get 1. 
Lemma 2.3. If in the 3x + 1-procedure for every natural number x there is a
number y < x then the 3x + 1-procedure for all natural x terminates at 1.
     Proof
     Assume that for any natural number x we obtain a number y < x in
the 3x + 1-procedure for x. We proceed by induction and show that then for
any natural number x the 3x + 1-procedure terminates at 1.
For x = 1 there is nothing to prove.
We consider x = 2. Then in the 3x + 1-procedure for x we get y = 1 < x.
Assume that the 3x + 1-procedure terminates at 1 for every y < x. Consider
the 3x + 1-procedure for x. By the assumption of lemma we get to some
y < x. Continuing the 3x + 1 procedure on y we get 1. 
Lemma 2.4. For a given natural number n, if x = 3n + 1, in the 3x + 1-
procedure for x there is an y < x.
      Proof
      Note that all numbers x of the form x = 3n + 1 are even. Therefore in
the first step for x we divide x by 2 and get x1 = y = 1/2 · x < x. 
Lemma 2.5. For a given natural odd number n, if x = 3n + 2, then in the
3x + 1-procedure for x there exits y < x.
      Proof
      Note that for all natural n, the number x = 3n + 2 is odd. Therefore in
3x + 1-procedure for x we get x1 = 3 · (3n + 2) + 1 = 3n+1 + 7. Moreover 8
divides x1 .
      For n = 1 we get x = 5 and x1 = 16. Then 8 divides x1 . Then y =
1/16x1 < x.
      For n = 3 we get x = 29, x1 = 88. Then 8 divides x1 and y = 1/8·x < x.
      Let x = 3n + 2, with n-odd. By induction on an odd n one can prove
that then 8 divides x1 . Namely assume that 8 divides x1 = 3 · (3n + 2) + 1 =
3 · 3n + 7 in the 3x + 1-procedure for such x. Consider x′ = 3n+2 + 2. Then
x′1 = 3 · (9 · 3n + 2) + 1 = 9 · (3 · 3n + 7) − 8 · 7. Thus 1/8 · x′1 = y ′ < x′ . 
Lemma 2.6. For a given natural numbers n, k, with n > 2, if x = 2n · 3k + 1,
then in the 3x + 1-procedure for x terminates at 1.

     Proof
     Our proof will be on the natural induction on the natural numbers
s = n + k.
     If s = n + k = 3 then n = 3, k = 0 and x = 8 and the hypothesis holds.
     Let us assume that the hypothesis holds for all natural s less than n + k.
     Let us use the 3x + 1-procedure for x = 2n · 3k + 1, which is an odd
number, for n > 2. Thus:
x1 = 3x + 1 = 2n · 3k+1 + 4, which is an even number. Thus:
x2 = 21 x1 = 12 (2n · 3k+1 + 4) = 2n−1 · 3k+1 + 2, which is an even number.
Thus:
x3 = 12 x2 = 21 (2n−1 · 3k+1 + 2) = 2n−2 · 3k+1 + 1.
As n − 2 + k + 1 = n + k − 1 < n + k, therefore x3 < x and by the induction
hypothesis, the 3x+ 1-procedure continued on x3 terminates at 1. The 3x+ 1-
procedure on x terminates at 1. 
Lemma 2.7. For a given natural number n, with n > 2, if x = 2n + 1, then
in the 3x + 1-procedure for x terminates at 1.
     Proof
     The proof is by induction o n, similarly as in Lemma 2.6 (for k = 0). 

      This follows from the fact that the 3x + 1-procedure for the numbers of

Lemma 4.1. If in the modified 3x + 1-procedure for every natural number x

Lemma 4.2. For a given natural even number n, if x = 3n + 2, then the
3x + 1-procedure for x there exists y < x.
      Proof
      For all natural n, the number if x = 3n + 2 is odd. Therefore consider
x1 = 3·(3n +2)+1. We prove that 2 divides x1 . For n = 2, y = 34 and 2 divides
y. Moreover 4 does not divide 34. Consider n = 4, then x = 34 + 2 = 83,
3 · 34 + 1 = 250 and 4 does not divides 250. For both numbers 34 and 250
the 3x + 1-procedure terminates at 1. Due to difficulties in proving that the
classical 3x + 1-procedure (in general) there exists a number y < x for the
numbers of the form y = 3n + 7 we present a simplified proof of that fact by
processing our modified 3x + 1 procedure for x.
      After a finite number of steps we get to the number of the form z =
2k · 3m + 1 for some natural k, m. Now we conclude via Lemmas 2.1 - 2.8 that
in the (modified) 3x + 1 procedure terminates for x at 1. 

5. Main theorem
In this section we prove the following theorem, which states the positive
solution of the 3x + 1 problem:
Theorem 5.1. For a given natural number x the 3x + 1-procedure on x, ter-
minates on 1.
      Proof
      Our proof will be on the natural induction on the number x.
      Assume now that the hypothesis holds for all natural numbers y smaller
that x ∈ N . We proceed the 3x + 1-procedure on x.
      If x is even, then x1 = 12 x and x1 < x. Therefore, by the induction
hypothesis, the 3x + 1-procedure on x1 terminates on 1.
      Assume, that x is an odd number. We express x in the binary system
as the sequence x = 1a1 a2 ...an 1, where a1 , ..., an ∈ {0, 1} for some natural
number n.
      We can easily assume that x is bigger than 23 · 3.
      For such x = 1a1 ...an 1 we obtain that x = 10...0 + ar a2 ...an 1 =
2n+2 + ar a2 ...an 1 where n is a natural number, r is the first index of a1 a2 ...an
different of 0 (if there is no such index, then x = 10...0 + 1 = 2n+2 + 1 and

by Lemma 2.7 we see that then 3x + 1-procedure ends at 1).
Note, that 2n+2 < x and ar a2 ...an 1 < x.
Thus 3x+1 = 3·2n+2 +[3(ar a2 ...an 1)+1] = 2·2n+2 +2n+2 +[3·(ar a2 ...an 1)+
1] = 2n+3 + 2n+2 + [3 · (ar a2 ...an 1) + 1].
      Using the classical (or our modified) 3x + 1-procedure on x we get:
x1 = 3x + 1 = 3(10...0 + ar a2 ...an 1) + 1 = 3(10...0) + [3(ar a2 ...an 1) + 1] =
3 · 2n+2 + [3(ar a2 ...an 1) + 1]. We observe, that the parity of x1 is exactly the
same as the parity of 3(ar a2 ...an 1) + 1. Therefore continuing the classical (or
our modified) 3x + 1-procedure on x1 , by the induction hypothesis applied to
the number a1 a2 ...an 1 we obtain a number xm of the form: xm = 3k · 2n + 1
or xm = 3k · 2n + 2 [or of the form xm = 2r · (3k · 2n + 1)], for some natural
(including 0) numbers k, n, r.
      Continuing the classical (or our modified) 3x + 1-procedure on xm we
conclude that it terminates at 1, by Lemmas 2.1 – 4.2. Finally we obtain,
that the 3x + 1-procedure on x terminates at 1. 
