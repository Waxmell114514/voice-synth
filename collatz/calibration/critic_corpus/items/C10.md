## Claim

Theorem. For any positive integer n > 1, the Collatz Conjecture is correct.


## Definitions used

For any positive integer n > 1, we consider a recursive algorithm by repeating
the following two steps A) and B).
   A) If n is an even number then n2 → n,
   B) If n is an odd number then 3n + 1 → n.
