## Claim

Theorem 3.4 There exists no natural number x0 for which C[x0 ] = 0.


## Definitions used

1    Preliminaries
Definition 1.1. Collatz Conjecture
Let a0 be a positive integer and consider the recursive sequence
                                     an−1
                                          2       , if an−1 is even
                               an =     3an−1 +1
                                            2     , if an−1 is odd

The conjecture asks if, for every a0 there exists an n such that an = 1. If an = 1, we say that a0
reaches 1.

Definition 1.2. Collatz Function
We define the Collatz function as follows:
                                       
                                         1 , if x reaches 1
                               C[x] =
                                         0 , if x never reaches 1

We proceed to define the available moves that a given number x can make in the Collatz Grid.
Number x is placed on the upper left corner of the grid and moves either horizontally or vertically
depending on its parity.

Definition 1.3. Collatz Grid Moves
A horizontal move (n) is defined as the application of the rule x 7→ 3x+1

A vertical move (k) is defined as the application of the rule x 7→ x2

According to the above, we are led to the last definition about the moves on the Collatz Grid.

Definition 1.5. Collatz Grid Moves
We define the natural numbers r1 , r2 , ..., rk , so that the number ri indicates the horizontal position
in which the i-th vertical move happened. The set (n, k, r1 , ..., rk ) is called a path.

In that way, we can encode the example paths as (n = 2, k = 1, r1 = 2) for the first one and
(n = 2, k = 1, r1 = 0), (n = 2, k = 1, r1 = 1), for the last two respectively.

Definition 1.6. We define the function f (x0 , n, k, r1 , ..., rk ) to be the value that results if we
apply the path (n, k, r1 , ..., rk ) to the number x0 .

Definition 1.7. The Characteristic Function
We define the function F (n, k, r1 , ..., rk ) to be the smallest number that follows the path (n, k, r1 , , , , rk ).
