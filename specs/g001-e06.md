# g001-e06 规格：口元音按舌位高低设置腭咽口面积（低元音更开）

假设（见 reports/gen_001_plan.json）：每个元音目标带自己的腭咽口面积 A_vp，经已有的鼻腔三端口结点耦合，取代“口元音一律 A_vp = 0”。

**核实标记**同 specs/g0-seed.md：【已核实 Nx】= 本次实际读到；【推导】= 由已核实内容或读代码推出；【未核实】= 记忆或仅检索摘要。

---

## 1. 文献

### 1.1 软腭高度随元音高低变化（定性，证据一致）

- Moll & Shriner 1967（N1，Cleft Palate J. 4:58–69，cinefluorography）【已核实 N1 p.65–66】：持续 /u/ 的腭（软腭）抬高大于 /a/；鼻辅音–元音音节中，含 /u/ 的音节平均软腭高度高于含 /a/ 的。作者把高低元音的差别归因于舌位对软腭运动的机械限制（腭舌肌连接），而不是说话人为避免鼻音而主动调节。文中引用 Moll 1962（JSHR 5:30–37，“Velopharyngeal closure on vowels”）支持“高元音腭抬高更大”。
- Moll 1962 原文未读。检索摘要的二手转述称低元音 /a ɔ/ 的腭咽间隙大于 /i u/【未核实】。
- Amelot & Rossato 2006（N2，法语，2 名说话人）【已核实 N2 §1、§3.2】：
  - 转述 Clumeck 1976（六种语言光电检测）：口元音中 /a/ 的软腭低于其他口元音。
  - 转述 Durand 1953（法语 X 光）：口语境中的 /a/（“il l'a”）软腭距咽后壁 **10 mm**，即口元音 /a/ 可能带开放的腭咽口。
  - 转述 Maeda 1993（发音合成 + 感知）：腭咽口约 **0.4 cm²** 已足以让 [i] 听起来鼻化，而 [a] 需要 **> 1.6 cm²** 才被感知为鼻化。
  - 转述 Benguerel 等 1975 / Warren 等 1993：塞音只容许 < 0.1 cm² 的腭咽开口。
  - 本文数据：说话人 S1 口元音 /a/ 的软腭高度均值 0.87 cm，/i u e o/ 为 0.978 cm，差异显著（S2 的数字在原文中看似有排版错误，不采用）。作者同时指出，他们的数据中元音高低与软腭高度之间没有一致的相关。
- Kunay, Hoole, Gubian 等 2022（N3，JASA 152:3483，33 名德语说话人，实时 MRI）【已核实 N3 摘要与讨论】：软腭下降程度的顺序为 /a/ > /o/ > /i, ø/（紧元音），在鼻音语境（N）与口音语境（C）中都如此，但并非所有两两比较都显著；N 语境的软腭下降幅度是 C 语境的约 3.5 倍；作者认为决定因素更接近舌的收紧位置，而不是语音学上的“元音高低”。注意：该研究测的是软腭位置（PCA 分数），C 语境中软腭降低**不等于**腭咽口打开。
- Bell-Berti 1973/1976/1980：只见于 N2、N3 的二手引用（腭提肌活动在低元音时较低）。原文未读【未核实】。

### 1.2 口元音腭咽口面积的生理量级（cm²）

| 量 | 值 | 状态 |
|---|---|---|
| 正常说话人在压力辅音（"hamper" 的 /p/）上的腭咽口面积 | 0.0–0.049 cm²（181 名“闭合充分”组）；Warren 的标准：正常非腭裂说话人不超过 0.05 cm²；> 0.20 cm² 为闭合不全 | 【已核实 N4，Dalston, Warren 等，对 Warren 1975/1979 的转述】 |
| 口元音 /a/ 的软腭–咽后壁距离（法语，X 光） | 10 mm（距离，不是面积） | 【已核实 N2 对 Durand 1953 的转述】 |
| 感知鼻化所需开口 | [i] ≈ 0.4 cm²；[a] > 1.6 cm² | 【已核实 N2 对 Maeda 1993 的转述；Maeda 原文未读】 |
| 鼻辅音（男）A_vp | /m/ 1.04，/n/ 1.2 cm² | 【已核实 g0-seed S11】 |
| g0-seed 中“0.01–0.15 cm²、0.16 cm² 后饱和” | — | 仍【未核实】，且与 Maeda 的阈值（0.4 / 1.6 cm²）**不一致**，建议不再引用 |
| 普通话数据 | 未找到普通话口元音腭咽口面积或软腭高度的测量。普通话鼻流量（nasalance）研究（如 400 名成人的方言/性别差异研究）只给出元音的鼻流量分数；高元音的鼻流量受经腭传导影响，不能换算为 A_vp | 【未核实：只读了检索摘要】 |

结论【推导】：口元音在非鼻音语境中，A_vp 的合理范围是 0 到约 0.1–0.2 cm²。低元音 /a/ 可在上端，高元音应接近 0。证据只到量级，没有逐元音的数值。由于 Maeda 的感知阈值，/a/ 带 0.1–0.3 cm² 的开口不会听起来鼻化，但会在 F1 附近引入极零对，改变 F1 的位置和带宽。

## 2. 模型

### 2.1 参数化（三档，而不是每元音一个）

元音高低分档【推导，普通话元音高低按一般语音学，未核实】：
- 低：a、（ia、ua、ai、ao、an、ang 中的 a 目标同为 a）
- 中：o、e（[ɤ]）、E（ê）、schwa、er
- 高：i、u、v（ü）、ii（ɿ）、iii（ʅ）

```
A_vp(vowel target v) = vp_oral_low   若 v ∈ 低
                     = vp_oral_mid   若 v ∈ 中
                     = vp_oral_high  若 v ∈ 高
```
在 `plan()` / `_syllable()` 中，元音关键帧的 `Avp` 由 0 改为上式。辅音关键帧：塞音、擦音、塞擦音保持 0（N4：压力辅音 < 0.05 cm²）；鼻音保持 `velum_open_area`；l、r 近音取所在元音的值【推导】。
关键帧之间的线性插值（现有 render）自然产生鼻韵尾前的协同鼻化斜坡，不需要新增参数。

### 2.2 新参数

| 名称 | 含义 | 单位 | 范围 | 默认 | 依据 |
|---|---|---|---|---|---|
| `vp_oral_low` | 低元音 a（非鼻音语境）的腭咽口面积 | cm² | 0.0–0.30 | 0.05 | 上限：Durand /a/ 10 mm 间隙、Maeda [a] 1.6 cm² 才感知为鼻化 → 0.3 留出余量【推导】；默认 0.05 = Warren 正常上限，取保守值【推导】 |
| `vp_oral_mid` | 中元音的腭咽口面积 | cm² | 0.0–0.15 | 0.02 | 介于低、高之间【推导/未核实】 |
| `vp_oral_high` | 高元音的腭咽口面积 | cm² | 0.0–0.05 | 0.0 | Moll & Shriner：高元音腭抬高最大；Maeda：[i] 0.4 cm² 已鼻化 → 上限取 0.05【推导】 |

共 3 个标量。若坚持每元音一个（Planner 写的 6–11 个），范围按上表的高低分档设定。但没有逐元音的文献值，多出的自由度只会被优化器用来拟合 M1 的 18 个数（g001-e00 的 Critic 已指出过拟合风险），**不推荐**。
可选的单调约束：vp_oral_high ≤ vp_oral_mid ≤ vp_oral_low。范围本身已大致保证，实现可在使用时取 `min`。

默认值的选择：若希望与 g0 对照严格可比，可把三项默认都设 0（等价于 g0），让优化器决定。

## 3. 必须先处理的内核问题（读代码得出）【推导】

`engine/tract/kl.py` 的三端口结点把鼻腔支路的导纳取为 `a3 = Avp`，但鼻腔第 0 段在随后的鼻腔结点（k=0）和能量和中用的是 `An[0]`（`nasal_area` 首元素，默认 1.2 cm²）。后果：
1. **Avp 很小时鼻孔输出不趋于 0。** 结点压力 pj 几乎全部进入鼻腔第 0 段（`nfn[0] = pj − bn[0]`），之后在面积 An[0] 的管中不经衰减地传到鼻孔，`u_nose` 与 Avp 无关地大；只有回到口腔的耦合随 Avp 变小。物理上，窄口（Avp）进入宽管（An[1]）时透射压力约为 2·Avp/(Avp+An1)，应趋于 0。
2. **Avp = 0 与 Avp = 0⁺ 不连续**：Avp=0 时代码走“闭端”分支（`nfn[0] = bn[0]`），Avp>0 时鼻腔入口变成被 pj 驱动的开口。
3. 能量 E 对鼻腔第 0 段用 An[0] 加权，与结点用的 Avp 不一致，所以即使面积固定，E 也不一定单调。系统本身仍稳定，相当于一个对角相似变换，但 E 不是正确的 Lyapunov 函数。

在 g0 中这个问题只在鼻音（Avp = 0.6 vs An[0] = 1.2）时出现，影响有限。e06 让每个口元音都带 0.01–0.3 cm² 的小开口，问题 1 会让所有元音都带上很强的鼻孔辐射，实验结论将不可信。

**建议修正**（物理一致、对 T0 无影响）：把鼻腔第 0 段视为面积等于 Avp(t) 的腭咽口管段，即鼻腔 k=0 结点用 `a1 = Avp[blk]`（而不是 `An[0]`），能量和中鼻腔第 0 段也用 Avp 加权。Avp → 0 时，该结点对鼻腔侧给出刚性反射（`nfn[1] = bn[1]`），连续地退化为闭端。可以删去 `Avp <= 0` 的特判，但要防止除零：`a1 + a2 > 0` 恒成立，因为 An[1] > 0。
验证用例：Avp ∈ {0, 1e-4, 0.01, 0.1, 1.0}，元音 /a/，鼻孔输出 RMS 应随 Avp 单调增加，且在 1e-4 处约为 0。
这一修正也会改变鼻辅音的音色（等效于鼻腔入口变窄），须与 e06 一起重新优化 `velum_open_area`、`nasal_area`。

## 4. 对 T0 的影响

- `tube_impulse_response`：调用 `kl_run` 时 `Avp = 0`，鼻腔分支不参与（ENGINE_API 方案 C），**均匀管结果不变**【推导，读 engine/t0_api.py】。第 3 节的修正在 Avp=0 时与原闭端行为一致：鼻腔与口腔结点完全解耦。
- `zero_input_energy`：用 `velum_open_area` 与 `area_a`。三端口结点本身无损。若做了第 3 节修正，能量加权一致，单调性更有保证；若不修正，现状（g0 已通过）不变。e06 本身不改这个钩子。
- 结论：e06（含第 3 节修正）**不改变 T0 均匀管结果**。

## 5. 实现者注意

1. 只改 control 层（`gestures.py` 的元音关键帧 Avp）加第 3 节的内核修正。没有第 3 节修正，不要跑 e06。
2. kv（耦合点）由 `velum_pos_frac` 决定。若同时采用 e01，女性悬雍垂位置约在 0.37–0.45（见 specs/g001-e01.md），耦合点位置会显著影响极零对的频率。
3. M1 用孤立元音（无鼻音语境），e06 只影响口语境下的低/中元音；M2/M3 的连续语流中，鼻韵尾前后已有 `velum_open_area` 的插值斜坡，e06 会让斜坡起点不再是 0。
4. 预期效应小。Planner 已标为探索性。若优化器把三项都推到 0，那就是“无效”的结论，不是实现错误。
5. 不要在 schema 中引用 g0-seed 的“0.16 cm² 饱和”（未核实且与 Maeda 冲突）。
