# g002-e03 规格：按 1/√A 分布的无状态边界层损耗

父代：main（g002-e00p 参数热启动）。改动模块：tract（`engine/tract/kl.py` 的损耗步、`engine/synth.py`、`engine/t0_api.py` 的参数传递、`params/schema.json`）。
核实标记同 specs/g002-e01.md。来源编号见文末；S1、S2 沿用 specs/g001-e04.md。

与 g001-e04 的区别：e04 用每段一阶搁架滤波器实现 √f 依赖，滤波器状态使“行波能量和”在 0.05 cm² 时微升，被拒。本假设**只保留逐段标量增益**，没有任何状态，频率依赖在参考频率处冻结。

## 1. 物理依据

### 1.1 单位长度衰减
刚性光滑圆管的黏滞 + 热传导（Kirchhoff）衰减：**α = 1.2×10⁻⁵ · √ω / r**（α 单位 m⁻¹，r 单位 m；ω = 2πf）【已核实 S1 Eq.2（Hanna 等 2016 引 Fletcher & Rossing），见 g001-e04 规格】。
r 用 cm 时常数数值不变：α[cm⁻¹] = 1.2×10⁻⁵·√ω / r[cm]【推导】。
圆截面 1/r = Π/(2A)（Π 周长），代入：
```
α = 0.6×10⁻⁵ · √ω · (Π/A),    Π/A = 2√(π/A)  （圆截面，A 单位 cm²，Π/A 单位 cm⁻¹）
```
即衰减 ∝ 周长/面积 ∝ 1/√A，∝ √f【推导】。
Flanagan 1972 第 3 章的传输线元件形式：串联电阻 R = (S/A²)·√(ωρμ/2)，并联电导 G = S·(η−1)/(ρc²)·√(λω/(2c_pρ))（S 为周长），两者都 ∝ 周长、∝ √ω，给出同样的 Π/A 标度【未核实：只见二手转述（检索摘要引 Flanagan 1972 pp.28–35），G 式中 ρ 的位置二手来源互相矛盾】。Ishizaka, French & Flanagan 1975、Sondhi & Schroeter 1987、Story 1995 学位论文中 KL 的具体离散化：**本次都没有读到原文**【未核实】。

### 1.2 换成每段每采样的衰减
KL 网格：段长 Δ = L/N，仿真率 fs_sim = N·c/L，每段每方向一个采样【已核实：读了 kl.py 文件头】。行波走过一段衰减 e^{−αΔ}，所以
```
μ_k^bl ≈ α_k·Δ = 0.6×10⁻⁵ · √ω_ref · Δ · 2√(π/A_k)
```
（αΔ ≪ 1，e^{−x} ≈ 1 − x，误差 < x²/2 ≈ 10⁻⁵）【推导】。

### 1.3 与带宽的关系（量级核对）
均匀衰减 μ 对应的共振带宽 B = −fs_sim·ln(1−μ)/π ≈ fs_sim·μ/π = c·α/π（与离散化无关）【推导】。
| 情况 | μ（每段每采样） | B |
|---|---|---|
| 边界层 κ=1，A = 2 cm²，f_ref = 500 Hz | 3.0×10⁻⁴（L=15.0） | ≈ 9 Hz |
| 同上，A = 0.15 cm² | 1.1×10⁻³ | ≈ 34 Hz（只在收紧段局部） |
| 父版本 wall_loss = 0.01（e00p 贴上限，r_g=1、r_lip=0.995） | 0.01 | **≈ 330 Hz**（L=15.04，fs_sim≈102 kHz） |
| 实测女性闭声门 B1–B3（Hanna 2016，中性元音） | — | 70–90 Hz，随频率变化很小【已核实 S1】 |
【推导，除标注外】

判读：
1. 纯边界层（κ=1）只贡献约 10 Hz，远小于实测的 70–90 Hz。Hanna 2016 要把 α 放大约 5 倍，刚性管模型带宽才与男性实测相当，原因是表面/体积比更大、壁非刚性、表面湿润【已核实 S1】。
2. **可屈服声壁的损耗也按 周长/面积 标度**：壁导纳按单位壁面积给出，单位长度的并联导纳 ∝ 周长 Π，再除以特性阻抗中的 A，衰减同样 ∝ Π/A【推导】。它在低频（F1 附近）占主导、随频率下降（质量控制）【未核实：凭记忆，Ishizaka 等 1975 的壁阻抗测量未读】。所以本假设的 1/√A 项在参考频率上**可以同时代表边界层和壁振动**，κ 大于 5 时应理解为“含壁振动的集总系数”，不再是纯边界层。
3. 父版本 330 Hz 的均匀带宽比实测大 4 倍，说明优化器在拿 wall_loss 做别的事（plan rationale：避免 Burg 贴到 F0 谐波）。本假设不能证明这一点，只给它一个物理上更合理的去处。
4. 参考频率冻结的后果：真实边界层带宽 ∝ √f（2500 Hz 处约为 500 Hz 处的 2.2 倍），本模型各共振峰带宽不随频率增长。实测（第 1 条）几乎不随频率变化，所以冻结反而更接近实测【推导】。

## 2. 离散实现

```
μ_k  = wall_loss + κ_bl · K0 · Δ · 2√(π / A_k)        K0 = 0.6×10⁻⁵·√(2π·f_ref)；f_ref = 500 Hz → K0 = 3.363×10⁻⁴（Δ 用 cm、A 用 cm² 时 μ 无量纲）
g_k  = 1 − min(μ_k, 1)                                 g_k ∈ [0, 1]
f_k ← g_k · nf_k ，  b_k ← g_k · nb_k                  （替换 kl.py 中统一的 g = 1 − mu）
```
- 数值：f_ref = 500 Hz 时 0.6×10⁻⁵·√3141.6 = 3.363×10⁻⁴；乘 Δ（cm）与 2√(π/A)（cm⁻¹）后无量纲【推导】。把 0.6×10⁻⁵·√(2π f_ref) 写成代码常数，注释引本规格；f_ref 不作参数。
- Δ = tract_length_cm / N。Δ 显式进公式，使 κ_bl 的物理含义不随声道长度变化（L 调参时损耗仍是“单位长度”的）【推导】。
- A_k 取**当前采样的插值面积 Ab[k]**（与结点散射同一个面积），每采样每段一次 sqrt；44+Nn 段的开销可以忽略。也可按控制块算一次，但那样面积插值与损耗不同步，不推荐。
- A_k 下限：Ab 已被 min_area（≥ 0.001 cm²）截过；为保险，sqrt 前再取 max(A_k, 1e-6)。A = 0.001 cm² 时 2√(π/A) = 112 cm⁻¹，κ_bl = 20 时 μ^bl ≈ 0.27：窄闭塞段衰减很大，物理上合理（闭塞本该近似隔断）。`min(μ,1)` 保证 g ≥ 0。
- 鼻腔支路：同样施加，第 0 段用 avp、其余用 An[k]。avp = 0 时 μ 被截到 1、g = 0，与现有“软腭关闭时清零第 0 段”一致。

### 2.1 参数

| 名称 | 含义 | 单位 | 范围 | 默认 | 依据 |
|---|---|---|---|---|---|
| `bl_loss_kappa`（新） | 1/√A 损耗系数，相对“刚性光滑圆管 Kirchhoff 衰减在 500 Hz 的值”的倍数 | 1 | **0–20** | **0**（μ_k ≡ wall_loss，逐采样复现父版本） | κ = 1 为纯边界层物理下限【已核实 S1 的 α 常数】；≈ 5 为 Hanna 2016 匹配实测所需倍数【已核实 S1】；5–20 表示同时吸收壁振动等 ∝ Π/A 的损耗【推导】 |
| `wall_loss`（已有） | 均匀常数衰减（声门端漏失、非 Π/A 部分的集总） | 1 | 0–0.01（不变） | 0.0015（不变） | 不改 |

- 名字含 `loss`，T0 的“低损耗角点”会自动把它置 0（plan 要求）。
- 与 plan 的 k_bl 写法换算：plan 的 μ_k = wall_loss + k_bl·(Π/A)_k 中 k_bl = κ_bl·3.363×10⁻⁴·Δ（cm）。L = 15 cm 时 κ_bl = 1 ↔ k_bl = 1.15×10⁻⁴ cm【推导】。用 κ 而不是 k_bl，是因为 k_bl 含 Δ，调长度时含义会漂移。
- **壁振动是否保留在 wall_loss**：保留 wall_loss 作为均匀项，不拆分。理由：壁振动本身也 ∝ Π/A（1.3 节第 2 条），已可由 κ 吸收；wall_loss 留作“非面积相关”的残余（声门开相漏失的平均、湿表面等）。若调参后 wall_loss → 0 而 κ 升高，说明损耗确实集中到窄处，这正是 plan 的预测【推导】。

## 3. 能量（零输入逐采样不增）

存储能量 E = Σ_k A_k (f_k² + b_k²)（含鼻腔）【已核实：ENGINE_API.md 与 kl.py】。面积固定时：
- 结点散射功率守恒：Σ A (nf² + nb²) 在一次散射前后相等（并联结点、三端口结点均如此）【已核实 S6，见 g0-seed】；
- 两端反射 |r_g|、|r_lip|、|r_nose| ≤ 1 只会减少；
- 损耗步每段乘 g_k²≤ 1：E_new = Σ A_k g_k² (nf_k² + nb_k²) ≤ Σ A_k (nf_k² + nb_k²) ≤ E_old【推导】。
**没有任何状态变量，能量函数仍是 ENGINE_API 规定的行波能量和，不需要 Critic 重新认可能量定义。** 这是与 g001-e04 的根本区别。
注意：g_k 必须 ∈ [0, 1]。不得为了“补偿”而让任何段 g_k > 1（例如把 wall_loss 写成负数）；schema 下限 0 已保证。

## 4. T0 均匀管钩子

ENGINE_API：钩子两端理想终端（声门全反射、唇端 −1），关闭辐射、末端修正和可屈服声壁，“**均匀分布的常数壁损耗可保留**”【已核实 eval/ENGINE_API.md】。
- 均匀管各段 A 相同，μ_k 在管内处处相等、与频率无关：属于“均匀分布的常数损耗”，**条文允许保留**【推导】。
- 现行钩子传的是 `_default("wall_loss")`（schema 默认 0.0015），不是调参值【已核实 t0_api.py】。本假设：钩子同样传 `_default("bl_loss_kappa")`（= 0），**走同一个内核、同一段损耗代码**。钩子语义（理想终端）一个字都不改（g001-e02 的教训）。

### 4.1 对 17.5 cm、3 cm² 管峰值的影响（容差 2%）
理想终端下，均匀增益 g 只把所有极点的半径缩到 g、角度不变：|H| 的峰位**完全不动**。唯一的偏移来自钩子输出的一阶差分（×|1−e^{−jω}|，随频率上升，把峰往高频推），量级 Δf ≈ (B/2)²/f₀【推导】。我在草稿区按 N = 44、fs_sim = 88 kHz、闭–开管直接算 |H| 峰位：

| 管内总 μ | 对应 B | 500 Hz 峰偏移 | 1500 Hz | 2500 Hz | 情形 |
|---|---|---|---|---|---|
| 0.0015 | 42 Hz | +0.18% | +0.02% | +0.01% | **现状 = 本假设钩子（κ 默认 0）** |
| 0.00177 | 50 Hz | +0.25% | +0.03% | +0.01% | 若钩子取 κ = 1 |
| 0.00287 | 81 Hz | +0.65% | +0.07% | +0.03% | 若钩子取 κ = 5 |
| 0.00697 | 196 Hz | **+3.97%** | +0.44% | +0.16% | 若钩子取 κ = 20（schema 上限） |
| 0.0115 | 324 Hz | **+11.7%** | +1.27% | +0.46% | 若钩子取 wall_loss = 0.01 |
【推导；3 cm² 时 κ·μ 单位量 = 3.363×10⁻⁴ × 0.3977 × 2.047 = 2.74×10⁻⁴】

结论：钩子用默认值（κ = 0）时峰位与现状完全相同（+0.18%），远在 2% 内。500 Hz 峰在管内总 μ ≲ 0.005（B ≲ 140 Hz）时都在 2% 内【推导】。
**陷阱**：钩子读的是 schema **默认值**。如果有人把 `wall_loss` 或 `bl_loss_kappa` 的 schema 默认改成调参结果（例如 0.01），T0 会在 500 Hz 偏 11.7% 而失败。schema 默认值保持 0.0015 / 0。T0 的峰值估计方法在 eval/ 内，我没读，实际偏移以钩子实测为准。

### 4.2 零输入能量钩子
`zero_input_energy` 须把 `P["bl_loss_kappa"]` 与 L 一起传进内核（它用调参值，不是默认值）。能量单调性由第 3 节保证；T0 的角点（全取 max：κ = 20、min_area = 0.05、wall_loss = 0.01）下 g_k 最小约 1 − (0.01 + 20·3.363e-4·Δ·2√(π/0.05))，仍 ∈ (0, 1)【推导】。

## 5. Implementer 注意事项

1. `kl_core` / `kl_run` 签名多一个 `kappa_bl`（和 Δ 或 L）。`kl_run` 是 T0 钩子的入口，**保持旧签名可用**：加关键字默认 0，或改调用处——两处调用（synth、t0_api）都要传，并让 Critic 看到钩子仍走同一内核。
2. 能量累加 `e += Ab[k]*(f²+b²)` 不变；损耗乘法改为逐段 g_k。不要在能量里加任何项。
3. 默认 κ = 0 时必须逐采样复现父版本：μ_k = wall_loss + 0·(…) = wall_loss，g_k 与父版本的 g 相同（`1.0 - mu` 的写法保持一致，避免 `1-(mu+0.0)` 与 `1-mu` 之外的重排）。验收：e00p 参数 + κ=0 的 wav 与 main 逐样本相同。
4. numba：sqrt 放在内层循环里没问题；不要为了“优化”预先按块算 g_k 而与插值面积脱节。
5. 调参：从 e00p 热启动，κ 初值可设 1（物理下限）而不是 0，让 CMA 的初始分布覆盖 1–5；wall_loss、r_glottis、r_lip 一起放开（三者与 κ 共同决定带宽）。
6. 报告：κ、wall_loss 终值；每个 T1 元音用引擎实测的 B1–B3（若有工具）；收紧最窄段的 g_k。
