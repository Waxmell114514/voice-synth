## 1. 连续时间模型

### 1.1 Flanagan 活塞辐射负载
唇端负载为辐射电阻 R_r 与辐射惯量 L_r **并联**：
```
R_r = 128/(9π²) · Z_c ≈ 1.441·Z_c ,     L_r = 8a/(3πc) · Z_c ,     Z_c = ρc/A_lip ,   a = √(A_lip/π)
Z_r(s) = s·L_r·R_r / (R_r + s·L_r)
```
【R_r、L_r 的形式和常数：两份二手来源一致（Picone 讲义；arXiv 2511.00428 给出带量纲形式 R_r = 128ρc/(9π²A)、L_r = 8ρ/(3π√(πA))，除以 Z_c 后与上式相同），Flanagan 1972 原书**未读**→【未核实（原文）】】。

### 1.2 加一个惯量系数 κ_rad
8/(3π) = 0.849 就是“有挡板活塞”的末端修正系数（L_r/Z_c = δ/c，δ = 0.849a）【推导】。把它换成参数 κ_rad：
```
τ = κ_rad · a / c ,     ρ_r = 128/(9π²) = 1.4410
z_r(s) = Z_r/Z_c = s·τ·ρ_r / (ρ_r + s·τ)
R_rad(s) = (z_r − 1)/(z_r + 1) = ( s·τ·(ρ_r − 1) − ρ_r ) / ( s·τ·(ρ_r + 1) + ρ_r )
```
- 低频 R_rad → −1，高频 R_rad → (ρ_r−1)/(ρ_r+1) = +0.181【推导】。
- κ_rad 的文献区间：无挡板圆管末端修正 ≈ 0.61a（Levine & Schwinger 1948）【二手来源核实 0.61；精确值 0.6133 未核实】；有挡板 ≈ 0.82–0.85a【0.849 = 8/(3π) 为推导；0.8216 未核实】。人头介于两者之间，plan 的 0.6–0.85 合理。

### 1.3 总反射：保留 r_lip 作为整体幅度
```
R(s) = r_lip · R_rad(s; κ_rad, A_lip)
```
- **κ_rad = 0 → τ = 0 → R_rad ≡ −1 → R ≡ −r_lip**，精确退化为父版本【推导】。
- |R(jω)| ≤ r_lip ≤ 1（z_r 为正实函数 ⇒ |R_rad| ≤ 1）【推导】。
- **与 plan 的一处不同**：plan 说 r_lip 将变成“高频极限”。按这个写法 r_lip 是**全频段的幅度系数**（低频 |R| = r_lip），高频极限是 0.181·r_lip。若只想让滤波器决定损耗，r_lip 应趋向 1；如果调参后 r_lip 仍明显 < 1，说明优化器仍要额外的、与频率无关的唇端损耗。这个写法是让 κ_rad = 0 精确复现父版本的唯一简单办法。

### 1.4 量级（女性 L = 15.5 cm，κ_rad = 0.85，r_lip = 1，均匀管近似）
B_rad ≈ −(c/2L)·ln|R|/π【推导】：
| A_lip | a | 500 Hz | 1 kHz | 2 kHz | 4 kHz |
|---|---|---|---|---|---|
| 5.0 cm²（/a/） | 1.26 cm | |R|=0.987, 5 Hz | 0.952, 18 Hz | 0.843, 61 Hz | 0.625, 169 Hz |
| 1.0 | 0.56 | 0.997, 1 Hz | 0.990, 4 Hz | 0.961, 14 Hz | 0.869, 51 Hz |
| 0.1（/u/） | 0.18 | 0.9997, 0.1 Hz | 0.999, 0.4 Hz | 0.996, 1.5 Hz | 0.984, 6 Hz |
（对比：父版本常数 r_lip = 0.995 → 全频段 ≈ 1.8 Hz；r_lip = 0.92 → ≈ 30 Hz）【全部推导】
这正是 plan 的论点：低频几乎全反射，高频与大唇口才辐射；/a/ 与 /u/ 的辐射带宽相差两个数量级。

## 2. 离散化：一阶波数字滤波器（WDF）并联三端口

### 2.1 为什么用 WDF 而不是直接差分方程
双线性变换 s = 2fs·(1−z⁻¹)/(1+z⁻¹) 可得 R_rad(z) = (b0 + b1 z⁻¹)/(1 + a1 z⁻¹)：
```
K = 2·fs_sim·τ = 2·(N·c/L)·κ_rad·a/c = 2N·κ_rad·a/L     （与 c 无关；N=44 时 K = 88·κ_rad·a/L，a、L 用 cm）
D = K(ρ_r+1) + ρ_r ;  b0 = (K(ρ_r−1) − ρ_r)/D ;  b1 = −(K(ρ_r−1) + ρ_r)/D ;  a1 = (ρ_r − K(ρ_r+1))/D
```
【推导】。但直接型的状态没有现成的“能量”定义，|R| ≤ 1 只保证总能量（对时间求和）不增，**不保证逐采样不增**——这正是 g001-e04 被拒的原因。WDF 结构自带一个逐采样不增的能量函数（Fettweis 伪功率）【WDF 无源性一般结论：凭记忆，未核实原文；下面的数值检验为推导】。

### 2.2 结构（每采样一次，替换 `nb_[N-1] = -r_lip * f[N-1]`）
以第 N 段（唇段）为端口 t，电导按 KL 的面积加权归一化到 G_t = 1：
```
g_L = 1/K      （惯量端口电导，WDF 电感端口电阻 = 2fs·L_r）
g_R = 1/ρ_r    （电阻端口电导；匹配电阻，入射波 a_R = 0）
入射：a_t = f[N-1]（已含上一步损耗），a_L = s（电感状态）
pJ   = 2·(a_t + g_L·a_L) / (1 + g_L + g_R)
b_t  = pJ − a_t
b_L  = pJ − a_L ;   s ← −b_L                      （WDF 电感：反射 = −延迟）
nb_[N-1] = r_lip · b_t
```
我在草稿区验证：该结构的冲激响应与 2.1 的 R_rad(z) 在 K = 0.05、0.8、6.3 时逐频点相差 < 3×10⁻¹⁵；|R| 最大值 = 1（DC）；Nyquist 处 = +0.1807【推导，数值检验】。

### 2.3 能量（含滤波器状态）
```
E = Σ_k A_k (f_k² + b_k²)  [+ 鼻腔，不变]  +  A_lip · g_L · s²  =  … + A_lip · s² / K
```
- 并联结点伪功率守恒：a_t² + g_L a_L² = b_t² + g_L b_L² + g_R b_R²（b_R = pJ 被电阻吸收）⇒ 出射 ≤ 入射；再乘 r_lip ≤ 1 只会更小。所以 E 逐采样不增（面积、K 固定时）【推导；草稿区用 1 段管 + 随机初值跑 2000 采样，ΔE ≤ 0 全部成立】。
- **新增的 A_lip·s²/K 项必须计入 `zero_input_energy` 的返回值**，否则电感释放能量时“行波能量和”会上升（与 g001-e04 同样的失败）。ENGINE_API 写的是“声道总存储能量（行波能量按面积加权之和）”；**加这一项须 Critic 事先书面认可它属于“声道总存储能量”**。这不需要改 eval/（钩子在 engine/），但若 Critic 不认可，本假设无法通过能量检查——这是本规格的**阻断项**，实现前先问。
- 零输入钩子的随机初值：s 也应由 seed 随机初始化（它是“内部状态”）。

### 2.4 时变 A_lip（咔哒与能量）
A_lip 每采样插值（e07c），K ∝ a 随之变。WDF 电感端口电阻变化时，若直接沿用旧的波变量 s，储能 A·s²/K 会跳变（可能变大）。**存功率归一化状态**：
```
保存 w = s · √(A_lip / K)       （储能 = w²，与 A_lip、K 无关）
每采样开始：s = w · √(K / A_lip)（用本采样的 A_lip、K）；结束后 w = s_new · √(A_lip / K)
```
这样参数变化本身不注入能量【推导】。A_lip 变化引起的行波能量变化与父版本相同（父版本的结点也有此性质），不属于本假设。

### 2.5 κ_rad = 0 及很小的 κ_rad
- K → 0 时 g_L = 1/K → ∞，WDF 公式除零；直接型则出现 z = −1 处的零极点对消（极点在单位圆上）。所以 **κ_rad = 0 必须走旁路**：`nb_[N-1] = -r_lip * f[N-1]`，输出式也用父版本原式，s 不更新（置 0）。这样才能逐位复现父版本。
- 很小的 K（例如 κ_rad < 0.05、A_lip = 0.01 cm²：K ≈ 0.02）时极点接近 −1，状态在 Nyquist 附近缓慢振荡，响应仍 |R| ≤ 1 且在可听频段 ≈ −r_lip，无害但浪费数值动态范围。建议判断 `K < 1e-3` 时也走旁路（并清零 w），并在 schema 中把 κ_rad 的范围设为 0–1.0【推导】。

## 3. 输出辐射与新反射的一致性

现状：唇端体积速度 u = A(1+r_lip)·f，synth 再一阶差分近似辐射（∝ dU/dt，即低 ka 活塞远场）【已核实 kl.py、synth.py】。
建议：
```
u_lip = A_lip · ( f[N-1] − nb_[N-1] )       （κ_rad > 0 分支）
```
即唇端体积速度 = A·(入射 − 反射)，与压力波 KL 约定一致；κ_rad = 0 旁路分支保留父版本原式 `Ab[N-1]*(1.0+r_lip)*f[N-1]`（两个式子数学相等，但浮点末位可能不同，逐位复现要求保留原式）。synth 的一阶差分不改。
- 一致性：低 ka 时活塞远场声压 ∝ jω·U，与一阶差分一致【未核实原文，物理常识】；ka > 1（/a/ 唇口 a = 1.26 cm 时约 f > 4.4 kHz）时真实远场不再 ∝ ω，一阶差分高估高频。另一个自洽选项是输出 ∝ pJ（R_r 两端压力，低频 ≈ jωL_r·U，高频 ≈ R_r·U），能同时得到高频变平。**本假设不改输出**，以免 T3 变化归因不清；pJ 方案记为后续选项。
- 鼻孔端仍为常数 −r_nose，不改。

ENGINE_API：唇端理想开口（压力反射 −1），关闭辐射阻抗和末端修正【已核实】。现行钩子显式传 `r_lip = 1.0`【已核实 t0_api.py】。

## 6. Implementer 注意事项

1. **先问 Critic**：能量定义加 A_lip·s²/K（或 w²）项是否接受。不接受就不要实现。
2. 每采样：取插值后的 A_lip = Ab[N-1] → a → K = 2N·κ·a/L；`K < 1e-3` 走旁路并令 w = 0。
3. 状态以 w（功率归一化）保存，跨控制块、跨 kl_core 调用（若 synth 分段调用）都要保留；签名增加 w 的输入/输出，与 f、b 一样就地更新。
4. 唇端反射在损耗步之前计算（与现有 `nb_[N-1]` 位置相同），之后 b[N-1] 照常乘 (1−μ)。
5. 能量累加里加 `w*w`（面积已含在 w 的定义里）。
6. 不要用 2.1 的直接型系数实现（无逐采样能量保证）；它只用来做单元测试：WDF 冲激响应 vs 解析 R(z)。
7. 单元测试：(a) κ=0 与父版本 wav 逐样本相同；(b) 固定面积、随机初值，T0 角点下能量差分 ≤ 0（含浮点容差）；(c) A_lip 从 0.1 线性变到 5 cm²，零输入时能量不增；(d) `velum`、`vowels` 序列咔哒比不高于父版本。
8. K 与 c 无关（K = 2N·κ·a/L），不要再乘 C_SOUND；单位：a、L 都用 cm。
