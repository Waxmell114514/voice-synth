## 1. 依据

### 1.1 Story, Hoffman & Titze 1997（SPIE 3033，R1）：三区定义与女/男比值

定义【已核实 R1 p.29】：
- 会厌喉段（epilarynx）：从声门上方到梨状窝汇入主声道处（声学定义；Yang & Kasuya 用会厌尖）。
- 咽段（pharynx）：会厌喉段末端到**悬雍垂尖**。
- 口腔段（oral）：悬雍垂尖到唇。

### 1.4 Story 2008 的 44 段面积函数中咽/口分界的位置

Story 2008（R4，即 g0 采用的面积函数）**没有给出**悬雍垂、会厌或任何咽/口分界的位置【已核实 R4：全文未提 velum/uvula/epiglottis】。R4 给出的相关事实【已核实】：
- 第 1 段=声门，第 44 段=唇；VTL = 44Δ。
- 梨状窝在计算中作为侧支，接在**距声门 2.4 cm** 处。
- 1994（STH96）与 2002 两套数据来自同一男被试；2002 版多数元音更长。[ʌ ɑ ɔ] 的咽腔加宽区在 1994 版约 3.5–9 cm，2002 版 2.5–9 cm（推测为喉下降）；[ɛ] 整体拉伸；[o ʊ u] 增长主要来自更明显的圆唇。

因此分界点只能推算。做法【推导】：假设分界点到声门的绝对距离在 1994 与 2002 两套数据之间不变（R4 指出咽腔上端在两版都在约 9 cm 处，[o u] 的增长在唇部，这一假设对 [ɑ ʌ o u] 较合理，对 [i] 较弱）。用 R2 的男性 Lp（几何法）和 R1 的男性“会厌喉段+咽段”（悬雍垂法），除以 Story 2008 各元音段长 Δ：

## 2. 变换公式

记源（男性轴）上的归一化位置 x ∈ [0,1]（0=声门，1=唇），两个折点 0 < x_e < x_b < 1：
- 区 E（会厌喉段）[0, x_e]，伸缩系数 s_e
- 区 P（咽段）[x_e, x_b]，伸缩系数 s_p
- 区 O（口腔段）[x_b, 1]，伸缩系数 s_o

因为引擎的总长由全局 `tract_length_cm` 决定（段数固定为 44），只有**相对**系数有意义。取口腔为参照 s_o = 1，用两个相对比值：ρ_p = s_p/s_o，ρ_e = s_e/s_o。

**正向映射**（源 x → 目标 y，分段线性、单调）【推导】：

```
S   = ρ_e·x_e + ρ_p·(x_b − x_e) + (1 − x_b)          # 归一化常数
y_e = ρ_e·x_e / S
y_b = (ρ_e·x_e + ρ_p·(x_b − x_e)) / S
W(x) = ρ_e·x / S                              , 0   ≤ x ≤ x_e
     = y_e + ρ_p·(x − x_e) / S                , x_e ≤ x ≤ x_b
     = y_b + (x − x_b) / S                    , x_b ≤ x ≤ 1
```

**逆映射** W⁻¹(y) 同样分段线性（各段斜率倒数），用于重采样。

**重采样**到 N=44 段（输出段 j 覆盖 y ∈ [j/N, (j+1)/N]）：

推荐（体积保持，窄收紧不丢失）：
```
A_out[j] = N · ∫_{j/N}^{(j+1)/N} A_src(W⁻¹(y)) dy
```
其中 A_src(x) 是源 44 段的分段常数函数（第 i 段覆盖 [i/N, (i+1)/N]）。实现上可把源函数在细网格（如 8×N 点）上求值后在每个输出格内取平均。也可用点采样（在输出段中心 y=(j+0.5)/N 取 A_src(W⁻¹(y)) 的线性插值），但咽段压缩到 0.5–0.6 时，[ɑ] 第 13–15 段的窄收紧（0.15 cm²）在点采样下可能被平滑掉或位置漂移，因此推荐用平均。【推导】
声学上，一个管段的惯性项与 ∫dx/A 成比例，顺性项与 ∫A dx 成比例，算术平均只保住后者，所以对收紧处略偏宽。若要更保守，可在收紧处（A < 0.5 cm²）改用调和平均。这是可选项【推导】。

**校验用例**【推导】：
- 均匀管 A_src ≡ A0 → A_out ≡ A0（与 ρ、x_b 无关）。
- ρ_e = ρ_p = 1 → W(x) = x，输出与输入逐段相同（平均法下精确相同）。
- [ɑ]、x_e=0.140、x_b=0.508、ρ_e=ρ_p=0.587：女性分界在 y_b ≈ 0.377，与 R2 女性 5.03/13.55 = 0.371 一致。

**总长**：变换不改变总长，总长仍 = `tract_length_cm`。若同时采用 g001-e03（每元音长度），先做本变换，再按 e03 拉伸到该元音长度；两者正交。

## 4. 对 T0 的影响

- `tube_impulse_response(area_cm2, length_cm, n)`（eval/ENGINE_API.md 第 2 节）直接把给定面积均匀分 44 段交给 `kl_run`，不经过 control/gestures。只要变换放在 control 层（构造元音目标时），T0 的路径**完全不变**。即使把变换放进 tract 层，均匀管经变换仍是同一个均匀管（2 节校验用例），结果逐样本相同【推导】。
- `zero_input_energy` 用 `area_a`；若改为用变换后的 `area_a`，结构上仍是固定面积的无源 KL 网络，能量单调性不变【推导】。
- 结论：**不改变 T0 均匀管结果**，前提是变换不引入新的段数或采样率变化。

## 5. 实现者注意

1. 变换放在 `engine/control/gestures.py` 的 `plan()` 里构造 `V[v]` 处，即在 `constrict()` 叠加辅音收紧**之前**；`place_*`（距唇比例）因此指变换后的轴，这与它“占声道长度比例”的语义一致。
2. `velum_pos_frac`（鼻腔耦合点，当前默认 0.5，第 21–22 段）是在**变换后**的轴上。女性悬雍垂附近位于 y ≈ 0.37–0.45（R2 女 Lp/Lt：ɑ 0.37、i 0.42、u 0.43）【推导】。本假设不要求改它，但优化器可能需要把它往 0.40 附近调；可选做法是把 kv 绑定到 y_b，但 kv 在一句中是常数，不能逐元音变化。
3. g001-e00 的面积参数是在均匀缩放下调过的；加入变换后须与新参数一起重新优化，否则对照不公平。`warp_rho_*` 和 `warp_x*` 必须加入 tools/optimize.py 的 M1 TARGETS。
4. 面积下限 `min_area` 在变换后再施加（render 中已有）。
5. 不要对占位元音（E、schwa、ii、iii、er）声称有文献分界；它们的 `warp_xb` 是占位值。
6. 风险：R1 自己的结果显示非均匀变换在 F1/F2 **绝对值**上未必比均匀缩放更好（1.1 节）；Story 2008 面积函数本身算出的 F2 偏低 20–36%（g0-seed 3.4 节），轴向变换不能修正截面误差。Planner 预测 −0.015 的依据较弱。
