## 1. 公式

沿用 Story 2005 Tier II（Eq.1、5–9）【已核实 P1】，只给舌背收紧多一个激活量 m，并对全部六个元音启用：

```
V(i)   = (π/4)·max(Ω(i) + q1·φ1(i) + q2·φ2(i), 0)²                    Tier I，不变
C_d(i) = max( 1 − m_v · d_c · exp(−ln16·((i − l_c)/r)²), 0 ),  r = r_b (i<l_c) 或 r_f (i≥l_c)
d_c    = 1 − a_c / V(l_c)                                               (Eq.6；V(l_c) 按分数段线性插值，下限 1e-9)
r_f = s·r_c/(1+s)，r_b = r_c/(1+s)，本假设 s = 1、r_c = 8（与父版本相同）
A(i)   = max( V(i) · C_d(i) · C_lip(i), min_area )                     唇口叠加 C_lip 不变
```
- v ∈ {a, o, e, i, u, v}（v = ü）。其他元音目标（E、schwa、ii、iii、er）**不加**舌背叠加，代码路径不变。
- m_v 就是 Story Eq.5 中的 m_c【已核实 P1：m_c 为激活量，m_c = 1 时恰好在 l_c 处达到 a_c】。本假设限定 m ∈ [0, 1]：m > 1 会把收紧“摊开”成闭塞，那是辅音的用法【已核实 P1 Table I：闭塞辅音 m_c 1.1–2.0】。
- **m = 0 时恒等**：C_d ≡ 1 − 0·(…) = 1（浮点下精确为 1.0），A 与不叠加逐位相同【推导】。实现时**不要**写成 `if m>0` 分支之外再做别的处理；直接按公式乘即可。唯一要防的是 0·inf = NaN：d_c 的分母已有 1e-9 下限，d_c 有限，安全【推导】。
- 0 < m < 1：最窄处面积 = V(l_c)·(1 − m·d_c)，介于 V(l_c) 与 a_c 之间，即“收紧做了一部分”【推导】。

### 1.1 叠加的已知副作用（Implementer 与 Critic 都要知道）
乘法叠加不保证 l_c 以外的段 ≥ a_c：A(i) = V(i)·(1 − m·d_c·g(i))，若 V(i) < V(l_c)（收紧中心落在底座的“鼓包”上），旁边的段可以比 a_c 更窄。例：V(l_c)=2、a_c=0.15、V(i)=0.5、g=0.9 → A(i)=0.084【推导】。所以 **a_c ≥ 0.15 不等于咽腔罚项一定不触发**。另：a_c > V(l_c) 时 d_c < 0，叠加变成**扩张**（Story 原式允许，父版本 lip_area 已经这样用）。父版本 /a/ 的底座在第 6–15 段只有 0.22–0.37 cm²【推导：用 params/g002-e01.json 算】，所以 /a/ 的咽腔“收紧”在很多 l_c 上实际是扩张或几乎不变，这是允许的，不是 bug。

## 2. 段号约定与女性解剖标志点

- 段号 1 起、1 = 紧贴声门上方、44 = 唇，按 44 段归一化位置；引擎 N ≠ 44 时由 `tier2_factor()` 换算（现有代码已做）【已核实：读了 story_modes.py】。
- Story 2018 女性版标志点（归一化位置）b = [0, 0.2412, 0.5666, 0.9090, 1]（声门、会厌上缘、HPSP、唇后缘、唇前缘）【已核实 P2 Table I，本次再次核对文本层】。换成段号（×44）：**会厌尖 ≈ 10.6，HPSP ≈ 24.9，唇区 40–44**【推导】。
- 因此：l_c ∈ 8–11 = 喉咽/会厌高度（舌根后缩、/ɑ/ 型咽腔收紧）；11–22 = 口咽；22–27 = 软腭（/u/ /o/ 型）；27–32 = 硬腭（/i/ /y/ 型）【推导】。
- 罚项的“咽腔”区间：`tools/plausibility.py` 用 `A[2:n//2]`，即 **第 3–22 段**，下限 `PHARYNX_MIN = 0.15`【已核实：读了代码】。

## 3. 文献实例与初值依据

### 3.1 Story 2005 Table II / 第 IV 节里**没有**元音收紧实例
本次重读 P1：Table II 只给液音 [ɝ]、[l] 的两收紧参数（ɝa: l_c=[12,35], a_c=[1.0,0.6]；ɝb: [12,32], [0.4,0.1], r_c=[4,6]；la: [12,40], [3.5,1.0]；lb: [12,40], [3.0,0.1]，r_c 均为 4，s=m=1）；第 IV 节的 VV/VCV 示例只让 q1、q2、m_c 随时间变，元音本身全部由 Tier I 生成，没有咽腔或硬腭收紧的元音实例【已核实 P1 Table II 与第 IV 节正文】。
**所以 plan 里“取 Story 2005 Table II 和第 IV 节的元音 l_c、a_c、r_c 实例”这一要求无法满足**。唯一可借的咽腔实例是 ɝb 的第一收紧（l_c = 12，a_c = 0.4，r_c = 4），它是卷舌音的咽腔收缩，不是元音【已核实 P1】。Story & Titze 1998（J. Phonetics 26:223）是否给出元音收紧参数：本次未取得原文【未核实】。
初值因此改用女声 MRI 实测（下一节），这一点比借英语男声参数更直接。

### 3.3 普通话的方向（只作参考）
- /a/：F1 偏低 14%（父版本 Critic 诊断）。咽腔收窄（l_c 靠近会厌）+ 口腔张大抬高 F1，这是 Fant/Stevens 三参数模型的经典结论【未核实：凭记忆，没读原文】。
- /i/、/ü/：硬腭处更窄、更长的收紧降低 F1、抬高 F2【未核实，同上】。父版本 /i/ 底座在第 30–33 段已低到 0.09–0.15 cm²（q1_i 贴在 −5.5）【推导】：加硬腭叠加的作用主要是**让 q1 离开下限**，用局部收紧代替整体前移，而不是把面积再压低。

## 4. 参数（写入 params/schema.json）

全部 `tune: ["M1"]`，`vowel` 字段照父版本写法。r_c 仍固定 8（`DORSAL_RC`），s = 1。

参数数 +12（6 个 m、a/i/v 各 lc、ac）。请 orchestrator 检查 `config.param_cap`。

**dors_ac 下限的取法（与 plan 有一处冲突，须 Planner 拍板）**
- plan 要求下限 0.15，与 `plausibility.PHARYNX_MIN = 0.15` 同源：e01 规格第 8 节，DJ /ɑ/ 0.18、/ʌ/ 0.21，Story 2008 男 /ɑ/ 0.15【已核实 P3；S5 见 g0-seed】。/a/ 的收紧就在咽腔，所以 **a 的下限取 0.15**。
- 但父版本调参得到 `dors_ac_u = 0.126 < 0.15`。若把 u 的下限也改成 0.15，热启动就**不能逐采样复现父版本**（优化器初始化会把它截到 0.15）。o、e、u 的收紧在父版本里都在第 18–26 段（口咽到软腭），**保持原下限 0.12**，第 3–22 段内是否过窄交给罚项判断（1.1 节已说明 a_c 并不直接决定罚项）。
- i、v 的收紧在硬腭（第 27–32 段），不在罚项的咽腔区间内；口腔最窄处 DJ /i/ 为 0.14（MRI），EBCT 低到 0.03–0.07，e01 规格第 8 节建议 i、ü 可到 0.06【已核实 P3】。取 0.08 留余量，避免过窄产生湍流需求【推导】。
- 若 Planner 坚持统一 0.15：u 的热启动值改为 0.15，并在报告中注明“非逐位复现父版本”。

**dors_ac 上限从 1.0 放到 1.5**：父版本 `dors_ac_e` 钉在 1.0 上限。现在 m 可以减弱收紧，理论上不必放宽；但 o、e 的底座在第 18–26 段约 0.7–1.4 cm²【推导】，a_c 允许略大于 V(l_c)（局部扩张）可以减少贴边。1.5 低于 DJ 咽腔典型值的上端（/æ/ 第 13–20 段 2.8–3.8）【已核实 P3】。

## 5. 热启动必须逐采样复现父版本（验收项）

1. 合并主线（含 e07c）后，先用父参数文件跑一次，记为“合并后父版本”基线；e02 与它比，而**不是**与 e01 原始 0.0429 比（那是没有 e07c 的引擎测的，见 plan rationale）。
2. 写热启动参数文件：父版本所有值原样；新增 `dors_m_a = dors_m_i = dors_m_v = 0`、`dors_m_o = dors_m_e = dors_m_u = 1`；a/i/v 的 lc、ac 取默认（m=0 时不起作用）。
3. 验收：`vowel_area()` 对六个元音与父版本逐元素 `==`（不是 allclose）；合成 `vowels`、`velum` 两个序列的 wav 逐样本相同。做不到即实现有误（常见原因：乘法顺序变了，例如先乘唇口再乘舌背；浮点乘法不满足结合律，A·C1·C2 与 A·C2·C1 末位可能不同。**保持父版本的顺序：先舌背、后唇口**）。

## 6. T0 与能量

- 只改元音目标面积的生成方式，不碰 `engine/tract/`。T0 均匀管钩子直接传面积，不经过 story_modes：**不受影响**【已核实：读了 engine/t0_api.py】。
- `zero_input_energy` 用 `P["area_a"]`（固定面积）；e01 分支若 `area_a` 不再是 schema 参数，须确认该钩子仍能取到一个面积（父版本既然 T0 通过，按父版本做法即可）。不改它。
- 能量逐采样不增、咔哒：面积目标变了，但时间插值与声道内核不变，预计与合并后父版本相同。

## 7. Implementer 注意事项

1. `DORSAL_VOWELS` 改为六个 T1 元音；`vowel_area()` 中舌背因子传 `mc=P[f"dors_m_{v}"]`。`tier2_factor()` 已支持 mc，不必改。
2. 段号是 1 起、按 44 段归一化的浮点数；不要四舍五入成整数（父版本也没取整）。
3. 罚项：调参目标仍是 T1 + 0.1×罚项。/a/ 在 l_c 8–14 时最容易触发 `pharynx_min`（1.1 节）；父版本 /a/ 第 4 段已是 0.06 cm²（会厌喉，第 3–22 段区间内）【推导】，所以 /a/ 的罚项可能在加叠加之前就非零，报告时把“加叠加前后”的 /a/ 罚项分开列。
4. `export_vowel_areas()` 要用新生成方式，`tools/plausibility.py` 才会给新形状打分（它优先调用该函数）。
5. 收紧位置 l_c 是连续参数，但 V(l_c) 用线性插值，目标函数对 l_c 只有分段光滑；优化器若是 CMA-ES 无妨，若用梯度法注意。
6. 报告中列出：每个元音的 m、l_c、a_c 终值，是否贴边（新范围下），以及第 3–22 段最小面积。
