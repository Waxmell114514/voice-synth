# g001-e03 规格：按元音变化的有效声道长度（固定段长 + 可变激活段数 + 声门端分数段）

假设（见 reports/gen_001_plan.json）：每个元音目标带自己的有效声道长度（喉位 + 唇突），取代全句单一 `tract_length_cm`。
仿真采样率保持固定，段长 Δ 固定，长度变化由“激活段数 M + 一个分数段 α”实现。

**核实标记**同 specs/g0-seed.md：【已核实 Vx】= 本次实际读到；【推导】= 由已核实内容或读代码推出；【未核实】= 记忆或仅检索摘要。

喉位：女性喉位随元音的变化（后/低元音较低）约 ±0.5 cm 量级【未核实】。

### 1.2 可变长度 KL / 分数延迟的做法

- Välimäki & Karjalainen 1994（ICSLP，V4）【已核实，读了第 2–4 页原文图像】：
  - 用分数延迟（FD）滤波器使每个管段长度可连续调节；在延迟线的分数点**读出**用插值（delay d），**写入**用“去插值”（deinterpolation，互补延迟 δ = 1 − d，系数与插值器相同但顺序相反，用转置 FIR 结构实现）。
  - 时变模型通过随时间改变 FIR 插值/去插值系数实现；原文：只要插值点变化不大，FIR FD 滤波器**不会产生明显的瞬态**。
  - 参考文献中列出的可变长度 KL 前人工作（仅核实了题录）：Strube 1975（JASA 57:256，非均匀无损管的可变长度采样表示）、Laine 1988、Wu, Badin, Cheng & Guerin 1987（ICPhS，KL 模型中声道长度的连续变化）、Wright & Owens 1993（IEEE TSAP 1(1):109，KL 模型中动态改变声道长度的多速率采样方法）。这些文章的内容【未核实】。
- Mathur, Story & Rodriguez 2006（IEEE TASLP 14(5):1754–1762）：半采样延迟 KL 模型中用分数延迟（Lagrange 插值）做段长的分数伸长，验证了唇突、喉下降和中间段伸长。原文未读；以下转述来自 Qureshi & Ishaq 2019（V5）【已核实 V5 中的转述】：
  - 总长 l = (M + α)·d，α ∈ [0,1]（V5 Eq.11）。
  - 伸长一个段 = 插入两个额外段（一个分数段、一个“虚拟段”），分数延迟用 Lagrange 插值（V5 用 3 阶）。
  - Lagrange 插值“幅频响应从不超过 1”（V5 转引 Välimäki 1995）。注意：严格地说这只对处于中心区间的分数延迟成立【未核实】；1 阶（线性插值）系数为非负、和为 1，必然 |H| ≤ 1【推导】。
  - V5 Tables 1–3：44 段、17.5 cm 中性元音，第 1 段（喉）或第 44 段（唇）伸长 50%，与 ABCD 传输矩阵法相比前五个共振峰误差 ≤ 0.17%【已核实】。
- Wright & Owens 1993、Välimäki 1995 博士论文中关于时变长度能量守恒的具体结论【未核实】。

## 2. 方案（固定仿真率，最大 N_max 段，激活 M 段 + 声门端分数段）

### 2.1 几何

- 参考长度 L_ref = `tract_length_cm`（保持现有参数，意义改为“参考声道长度”），N_ref = 44。
- **段长 Δ = L_ref/44 固定**，仿真率 fs_sim = 44·c/L_ref 与现在完全相同（`sim_rate(L_ref, 44, fs_out)`）。
- 每个元音目标 v 有长度比 λ_v（新参数）。该元音的有效长度 L_v = λ_v·L_ref。
- 每个控制帧，长度比 λ(t) 按 gestures 的关键帧线性插值（与面积同样处理）。
- 有效段数 Q(t) = 44·λ(t) = M(t) + α(t)，M = floor(Q)，α = Q − M ∈ [0,1)。
- 分配 N_max = ceil(44·λ_max) + 1 段（λ_max 为 schema 上限）。λ ∈ [0.85, 1.20] 时 N_max = 54【推导】。
- **唇端固定在数组末尾**（索引 N_max−1），声门端随长度移动：激活段为 k0 … N_max−1，k0 = N_max − M。k0 之前的段不参与计算，状态置 0。

### 2.2 面积函数到 M+α 段的映射

把该帧的 44 点面积函数 A44（声门→唇，若同时采用 g001-e01 则先做其轴向变换）在长度上**整体拉伸**到 Q 段：
```
对激活段 j = 0 … M−1（从唇端倒数第 j 段，索引 N_max−1−j）：
    段中心距唇 s_j = (j + 0.5)/Q     （归一化到 [0,1]，0=唇）
    A[N_max−1−j] = interp(1 − s_j; A44 位于 (i+0.5)/44, i=0..43)
分数段（声门端，长度 α·Δ）：面积取 A44[0]
```
整体拉伸与 Story 2008 的表示方式一致：每个元音都是 44 段，Δ 随元音变化，唇突和喉位差异已含在面积函数形状里【已核实 V3 的表示方式；用法为推导】。
可选扩展（不在本假设内）：把伸长分配到唇端（圆唇）或声门端（喉下降），每元音需两个参数。

### 2.3 声门端分数段（1 阶 Lagrange = 线性插值）

现有声门端：`nf[0] = r_g·b[0] + ug/A[0]`（压力波，见 engine/tract/kl.py）。
新声门端在激活首段 k0 处，增加长度 α·Δ 的分数段。它的往返延迟为 D = 2α 个采样（0 ≤ D < 2）。实现为一个 2 样本缓冲 z1, z2（保存 b[k0] 的过去值）：
```
x_n = b[k0]                         # 本采样到达声门端的后行波
D = 2α;   i = floor(D);   d = D − i
若 i == 0:  y = (1−d)·x_n  + d·z1
若 i == 1:  y = (1−d)·z1   + d·z2
nf[k0] = r_g·y + ug/A[k0]
z2 ← z1;  z1 ← x_n
```
α = 0 时 y = x_n，与现有代码**逐样本相同**【推导】。

**无源性**（固定 α）【推导】：线性插值输出 y² ≤ (1−d)·a² + d·b²（Jensen 不等式）。取存储量
V = A[k0]·(z1² + d·z2²)（i=1 时）或 A[k0]·d·z1²（i=0 时），可证 V 的增量 ≤ 输入功率 − 输出功率，因此整个网络在 r_g ≤ 1、面积固定时能量（含 V）单调不增。
**`zero_input_energy` 返回的能量必须把 V 加进去**，否则在 α ≠ 0 时“只算段内行波”的能量可能出现小幅上升。

**高频阻尼**【推导】：线性插值 d=0.5 时 |H(f)| = cos(πf/fs_sim)。fs_sim ≈ 106 kHz（L=14.5 cm）时 5 kHz 处 0.989。这一项每经过声门反射一次乘一次，相对 r_g（0.5–1.0）可忽略。若需更平坦，可改用 3 阶 Lagrange（V5 的做法）。但 3 阶在区间边缘 |H| 可能略大于 1，须检查【未核实】。
**不推荐 Thiran 全通**：它无损，但系数变化时会产生瞬态，且 d→0 时极点接近单位圆【未核实；Välimäki 等 1995 的“全通 FD 瞬态消除”论文未读】。

### 2.4 激活段数变化时的状态移交（时变长度）

λ(t) 变化使 α 越过 0 或 1 时，M 加减 1：
- **伸长**（α 由接近 1 跳到接近 0，M→M+1，k0→k0−1）：此时分数段约 1 整段，缓冲区 (z1, z2) 正好存着一整段往返的两个样本。把它们移交给新激活段：b[k0_new] ← z1，f[k0_new] ← 最近一次写入的前行波（= r_g·y + 激励）；然后缓冲区清零，重新从 α≈0 开始【推导】。
- **缩短**（α 由接近 0 跳到接近 1，M→M−1，k0→k0+1）：把被关闭段 k0_old 的 (f, b) 写入缓冲区（z1 ← b[k0_old]，z2 ← f[k0_old] 经 r_g 反射前的值），再把该段置 0【推导】。
- 面积：新激活段的面积按 2.2 节重算；控制帧之间面积已经是线性插值的，不额外平滑。

**能量守恒告诫**：
1. 长度随时间变化本质上是参数变化（相当于移动边界），即使离散化完美，存储能量 E 也**不再单调**；物理上移动边界会对声场做功（多普勒效应）。现有引擎在面积随时间变化时已经如此（kl.py 注释写明“面积不变时”才单调）【推导】。
2. 实际影响取决于变化速度：发音速率下 λ 每 50–100 ms 变化不超过约 0.1，即每采样 α 变化 ~1e-4，远小于 V4 所说“变化不大即无明显瞬态”的界限【推导；量级判断】。
3. 只要按 2.4 节做状态移交、不在 M 变化时丢弃或复制能量，就不会产生咔嗒声。若实现者选择最简单的“新段状态置 0、旧段直接丢弃”，会在每次 M 变化时产生一个小的能量不连续。这一做法可以接受，但必须在 30 句开发集上听辨或检查频谱中有没有周期性咔嗒。
4. T0 的能量检验（`zero_input_energy`）是静态参数，不涉及上述时变情形。

### 2.5 其他索引的重映射

- 噪声注入段 `nidx`、辅音收紧位置 `place_*`（距唇比例）：均以唇端为基准，索引 = N_max−1 − round(frac·(M−1))【推导】。λ=1 时与现在一致。
- 鼻腔耦合点 kv：软腭附着在硬腭后缘，**距唇的距离**大致不随喉位变化（唇突除外），建议按距唇计：kv = N_max−1 − round((1 − velum_pos_frac)·43)，λ=1 时与现值相同【推导；解剖判断未核实】。
- 鼻腔段数 Nn = round(nasal_length_cm/Δ)：Δ 固定，不变。
- 声门源注入 `ug/A[k0]` 用激活首段面积。

## 4. 对 T0 的影响

- `tube_impulse_response(area_cm2, length_cm, n)`：T0 给出显式长度。实现时令 L_ref = length_cm、λ = 1，则 Q = 44、M = 44、α = 0，分数段缓冲不起作用（y = x_n），激活段恰为 44 个，**与现有代码逐样本相同**【推导】。必须满足：
  1. λ=1 时 α 精确为 0（用 `Q = 44·λ` 后 `round(Q, 9)` 再取 floor，避免 43.9999999 → M=43、α≈1）。
  2. N_max > 44 的多余段在 λ=1 时完全不参与（状态为 0、不进入结点计算、不进入能量和）。
  3. T0 仍按 ENGINE_API.md 方案 C 用理想终端（r_g=1、唇端 −1），走同一个 `kl_run`。
- `zero_input_energy`：用 `area_a` 和 `len_ratio_a`（静态）。若 `len_ratio_a ≠ 1`，α ≠ 0，能量必须包含分数段缓冲 V（2.3 节），否则可能报能量非单调。最稳妥：zero_input_energy 也用该元音的 λ，并把 V 计入。
- 结论：**按上述条件实现时不改变 T0 均匀管结果**；主要风险是 α 的浮点边界和多余段被误激活。

## 5. 实现者注意

1. 这是 tract 内核改动（`kl_run` 需要逐块的 M、α），比 e01、e06 大。建议先写离线验证：均匀管 L=14.5、λ ∈ {0.9, 1.0, 1.07, 1.13} 的冲激响应共振峰，应满足 F_n = (2n−1)c/(4λL)，误差 < 0.5%（V5 的 50% 单段伸长误差 ≤ 0.17% 可作参照）。
2. 当前 `render()` 用 `dx_cm = L/N_SECT` 计算鼻腔段数，保持用 L_ref。
3. `len_ratio_{v}` 与 `tract_length_cm` 有一个冗余自由度（全体 λ 同乘 k 等价于 L_ref 乘 k，但仿真率随 L_ref 变化）。建议优化时固定 schwa 的 λ=1 或固定 `tract_length_cm`，避免优化器沿冗余方向漂移。
4. λ 插值在关键帧之间是线性的；鼻韵尾、辅音收紧关键帧必须带上所属元音的 λ（不要让它在辅音处回到 1，否则每个音节两次长度跳变）。
5. 本假设与 g001-e01 正交（先做轴向变换，再整体拉伸），可以组合。
6. 风险：V1 是英语单被试；Planner 期望 /e/ 用更长的声道来压低 F1/F3，但 V1 的 [ʌ] 比均值短（0.97），默认值与 Planner 的方向相反，靠优化器在范围内找。
