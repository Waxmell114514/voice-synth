# g0 种子引擎规格：LF 声门源 + Kelly-Lochbaum 声道（44 段 + 鼻腔支路）+ 最小普通话前端

目标音色：成年**女性**北方普通话。引擎只使用公开发表的声学/解剖数据，不含录音、不含训练权重（见 CONSTRAINTS.md 第 1、4 条）。

**核实标记约定**
- 【已核实 Sx】：我实际打开并阅读了来源 Sx（见文末来源表）中对应的公式/数字。
- 【推导】：由已核实公式做的纯数学推导或单位换算，未在文献中逐字找到。
- 【未核实】：凭记忆或仅凭检索摘要，未读原文。实现者应视为占位值，进入 params/schema.json 时取值范围要放宽。

## 1. LF 声门源模型

### 1.1 波形方程（Fant, Liljencrants & Lin 1985）

符号：E(t) 为声门流导数 dU_g/dt（单位 cm³/s²），T0 = 1/F0，t=0 为开相起点。

| 项 | 公式 | 含义 / 单位 | 状态 |
|---|---|---|---|
| 开相 0 ≤ t ≤ te | E1(t) = E0 · e^{αt} · sin(ωg t) | E0：幅度标定 (cm³/s²)；α：指数增长常数 (1/s)；ωg (rad/s) | 【已核实 S1 Eq.1/4 附近】 |
| ωg | ωg = π / tp（tp = 1/(2Fg)，ωg = 2πFg） | tp：流量峰值时刻 (s) | 【已核实 S1 Eq.5】 |
| 激励点 | Ee = −E0 · e^{α te} · sin(ωg te) | Ee > 0：最大负峰值幅度 | 【已核实 S1 Eq.5】 |
| 开相流量 | U(t) = E0·[e^{αt}(α sin ωg t − ωg cos ωg t) + ωg] / (α² + ωg²) | 体积速度 (cm³/s) | 【已核实 S1 Eq.4】 |
| 回复相 te < t < tc | E2(t) = −(Ee/(ε ta)) · [e^{−ε(t−te)} − e^{−ε(tc−te)}] | ta：回复相有效时长 (s)；ε (1/s) | 【已核实 S1 Eq.11】 |
| tc | tc = T0（原文："In practice it is convenient to set tc = T0"） | | 【已核实 S1】 |
| ε 的隐式方程 | ε·ta = 1 − e^{−ε(T0−te)}；ta 很小时 ε ≈ 1/ta | 用 ε0 = 1/ta 做初值，以不动点或 Newton 迭代，通常 3–5 次收敛 | 【已核实 S1 Eq.12】；迭代方法【推导】 |
| α 的隐式方程（周期净流量为 0） | ∫₀^{te} E1 dt + ∫_{te}^{T0} E2 dt = 0 | 见下 | 条件【已核实 S1，"zero net gain of flow within a fundamental period"】 |

α 方程的闭式展开【推导】：
- 开相积分 = U(te) = E0·[e^{α te}(α sin ωg te − ωg cos ωg te) + ωg]/(α²+ωg²)，其中 E0 = −Ee/(e^{α te} sin ωg te)。
- 回复相积分 = −(Ee/(ε ta)) · [ (1 − e^{−ε(T0−te)})/ε − (T0−te)·e^{−ε(T0−te)} ]。
- 两者之和 = 0，对 α 做二分或 Newton（α 可为负；先算出 ε，ε 与 α 无关）。实现上建议二分区间 α ∈ [−5·ωg, +5·ωg] 并检查符号变化【推导/未核实区间】。

**命名冲突警告**：Fant 等 1985 原文 Eq.6 把 2α/ωg 也记为 "Rd"，与下面 1995 年的 Rd **不是同一个量**。schema 中请命名为 `lf_Rd`（Fant 1995 定义）。【已核实 S1 Eq.6，S2】

| Rk | Rk = (Te − Tp)/Tp | | 【已核实 S2】 |

## 2. Kelly-Lochbaum 声道

### 2.1 散射结（压力波）

| 项 | 公式 | 单位 / 范围 | 状态 |
|---|---|---|---|
| 管道波阻抗 | R_k = ρc / A_k（体积速度为流变量） | 声阻 (g·cm⁻⁴·s⁻¹) | 【已核实 S4（JOS Ideal Acoustic Tube）】 |
| 反射系数 | k_i = (R_i − R_{i−1})/(R_i + R_{i−1}) = **(A_{i−1} − A_i)/(A_{i−1} + A_i)** | ∈ [−1, 1] | 阻抗形式【已核实 S3】；面积形式【推导】 |
| 散射 | f⁺_i = (1+k_i) f⁺_{i−1} − k_i f⁻_i；f⁻_{i−1} = k_i f⁺_{i−1} + (1−k_i) f⁻_i | 压力波，f⁺ 朝唇方向 | 【已核实 S3】 |
| 面积下限 | A_min = 0.01–0.05 cm²（避免除零；闭塞时 A→A_min 而非 0，或闭塞时直接 k=1） | | 【未核实】 |

### 2.2 两端边界

| 端 | 模型 | 状态 |
|---|---|---|
| 声门端 | p⁺_1 = (ρc/A_1)·U_g(t) + r_g·p⁻_1，r_g ≈ 0.7–0.97（理想闭声门为 +1；常用 0.75 左右） | 形式【推导自 S3/S4】，r_g 数值【未核实】 |
| 唇端（最简） | 唇端反射 r_L ≈ −0.85 ~ −0.95（理想开口 −1）；输出 p_out[n] = U_lip[n] − U_lip[n−1]（一阶差分近似辐射的 jω 特性） | 【未核实】 |
| 唇端（一阶滤波） | 圆形活塞于无限障板的低频近似：Z_rad = R_r ‖ L_r，R_r = 128ρc/(9π²A_L)，L_r = 8a·ρc/(3πc·A_L)，a = √(A_L/π)；离散化后成为一阶反射滤波器 | 【未核实】（Flanagan 1972，检索未找到可核对全文） |
| 鼻孔端 | 同唇端模型，用鼻孔面积 | 【未核实】 |

### 2.3 损耗

| 项 | 做法 | 典型量级 | 状态 |
|---|---|---|---|
| 壁 + 黏滞损耗 | 每段每次传播乘以 μ_k = 1 − σ/√A_k（窄段损耗大） | 等效 μ ≈ 0.995–0.999；目标是使 F1 带宽约 50–100 Hz | 【未核实】 |

## 3. 元音面积函数

### 3.1 来源与普通话情况

- **普通话 MRI**：Wang, Dang & Kong (Interspeech 2013) 用体积 MRI 测得 10 个普通话元音（含 a o e i u ü）的面积函数，8 名被试（6 男 2 女），女性声道 < 14 cm，全体 13.4–19.4 cm【已核实 S8】。**但论文只给图，未见数值表**（我检索了全文文本）→ 不能直接使用。
- **女性英语 MRI**：Story, Titze & Hoffman 1998 (JASA 104:471) 有 27 岁女性 10 个元音面积函数【题录已核实 S9；数值表未读到】。**强烈建议后续获取此文数表替换下面的男性数据。**
- **本规格采用**：Story 2008 (JASA 123:327) 男性 11 个英语元音，**原文即为 44 段**（第 1 段=声门，第 44 段=唇），每元音段长 Δ 不同【已核实 S5 Table I】。

### 3.2 男→女缩放（Story, Hoffman & Titze 1997）

| 女/男最大面积比（均值） | 0.78 | 【已核实 S7】 |
| 女性 VTL | /i/ 14.7，/a/ 13.6，/u/ 15.5 cm（男 16.1/17.3/18.0） | 【已核实 S7】 |
| 女性分区长度 (cm) | /i/：喉 2.0 咽 4.2 口 8.5；/a/：1.5/3.0/9.2；/u/：1.9/4.8/8.7 | 【已核实 S7 Table 1】 |

g0 做法（最简）：44 个面积值不变，总长取 **L_f = 0.85 × L_male**；由于 N 固定，各段等比缩短。非均匀方案（咽 ×0.63、口 ×1.05）需要知道每个元音的咽/口分界，Story 2008 未给 → 留给后续假设。面积整体乘 0.78 对无损共振峰无影响，只影响损耗与辐射，可选【推导】。

**固定 L 的问题**：Story 2008 中 VTL 从 16.11（æ）到 19.59（u）不等，主要差异来自唇突。g0 若用单一 L（建议女性 14.5 cm），/u/ /o/ 的有效长度被压缩，共振峰偏高约 5–10%【推导】。可选做法：把长度作为每个手势目标的参数，但这要求可变 Fs 或分数延迟，g0 暂不实现。

**五度 → Hz（女）**【公式推导，范围未核实】：取对数刻度
F0(T) = F_min · (F_max/F_min)^{(T−1)/4}，T ∈ [1,5]。
女声默认 F_min = 170 Hz、F_max = 320 Hz（参数 `f0_min`: 140–220，`f0_max`: 260–380）。检索摘要称 Jongman 等 2006 报告女声读 "ma" 四声时 F0 约 180–270 Hz【未核实，二手】。调型实现：每个音节在 0%、50%、100% 处给五度目标，线性插值（T3 用 3 个点 2→1→4）。

**三声变调**【未核实，通识】：T3 + T3 → T2 + T3；多个 T3 连续时按韵律词分组从左到右/按语法结构应用；"一""不"变调规则 g0 可暂不实现（但不得针对具体字符串特化，规则须按声调序列一般地应用，见 CONSTRAINTS 第 8 条）。

**音节时长（朗读语）**【未核实】：平均 180–250 ms/音节（约 4–5.5 音节/s）；单念 400–500 ms；T3 最长、T4 最短；短语末延长 20–50%。
