## 2. 预处理与 PCA 步骤

### 2.1 文献规定的部分
- Story 2018 第 II 节（对 Story 1996 男声 10 个元音）：PCA 前每个面积函数做 **3 点滑动平均**，**声门上第 1 段设为 0.5 cm²**，再**转成等效直径**，然后做 PCA；模型为 A(x) = (π/4)[Ω(x) + q1φ1(x) + q2φ2(x)]²，Ω 为平均（中性）直径函数，φ1、φ2 为前两个主成分，44 段声门→唇【已核实 P2 第 II 节原文】。
- Story 2005 附录 A：各面积函数**先归一化到各元音的平均声道长度**，再做 PCA；模态是按解释方差排序的前两个主成分（引 Story & Titze 1998）【已核实 P1 附录 A 原文】。
- 等效直径 D = √(4A/π)【已核实 P1、P2：方括号里是直径】。

### 2.2 文献没有写清、由我选定的部分【推导，须在报告中照此执行】
1. **顺序**：平滑 → 设第 1 段 = 0.5 → 重采样到 44 段 → 转直径 → PCA。（Story 2018 没写平滑与重采样的先后；Story 2005 没写重采样方法【未核实】。）
2. **3 点平滑的端点**：内部段 (A[k−1]+A[k]+A[k+1])/3；首末段用两点平均。首段随即被 0.5 覆盖，所以只影响唇口段。
3. **重采样**：长度归一化——每个元音的第 k 段（1 起）放在归一化位置 (k − 0.5)/n_v，44 段的第 j 段在 (j − 0.5)/44，对**面积**做线性插值（端点外推取端值）。这等价于“每个元音拉伸/压缩到同一长度、44 等分”；段号与 Story 女性版一样表示同一归一化位置。
4. **PCA**：X 为 10×44 直径矩阵，Ω = 列均值，Y = X − Ω，SVD；φ1、φ2 取前两个右奇异向量，**单位 2-范数**（ΣΦ² = 1）；q = φᵀ(D − Ω)。Story 男版模态看起来也是单位范数（女性版经变形后 Σφ² ≈ 0.82）【推导】。
5. **符号**：φ1 取使 q1(/i/) < 0；φ2 取使 q2(/u/) < 0（与 Story 的 [i]、[u] 象限一致）。
6. 敏感性：把第 3 步换成 PCHIP、或去掉平滑、或不设第 1 段 = 0.5，φ1、φ2 与基准的余弦都 ≥ 0.994，解释方差变化 < 2 个百分点【推导】。所以第 1–3 项的具体选择不影响结论。

### 2.3 与引擎长度的关系
DJ 平均声道长度 13.73 cm（10 个元音平均），短于 Story 2018 女性版 15.53 cm【推导；DJ 长度已核实 P3】。模态定义在**归一化位置**上，第 j 段 ↔ 引擎第 j 段，段长 = tract_length_cm/44，与父版本完全相同（父版本同样不在模态里携带长度）。**不改长度参数**；DJ 的长度只作为 q 的来源信息。引擎 N ≠ 44 时，`tier1()` 已有的直径插值照用。

## 4. 热启动：把父版本形状投影到新基底

父版本 = g002-e01 调参结果（params/g002-e01.json）。基底不同，无法逐采样复现（plan 已承认）。步骤：
1. 对每个 T1 元音 v：用父版本参数生成完整面积 A_par = vowel_area(P_par, v)（含唇口、舌背叠加）。
2. 初值：把父版本 **Tier I 底座**的直径 D_par = Ω_S + q1φ1_S + q2φ2_S 投影：q⁰ = Φ_Fᵀ(D_par − Ω_F)（Φ_F 正交，最小二乘即投影）。
3. 精化：唇口、舌背参数**原样保留**，只调 (q1, q2)，最小化 RMS_k[ln A_new(k) − ln A_par(k)]（Nelder–Mead，两维）。
4. 其余元音（E、schwa、ii、iii、er）同样处理（er、ii、iii 带各自的叠加）。
5. 新 q 若超出 3.5 节范围，截到边界并报告。
