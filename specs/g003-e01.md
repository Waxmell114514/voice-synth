### 1.2 由此推得的普通话女声长度差【推导 + 估计】

取唇突 ≈ 下唇前突（偏大估计），喉位差取德语均值，相对 /i/：

| 元音 | 唇（cm） | 喉（cm，降为正） | 合计 | 相对 15.04 cm |
|---|---|---|---|---|
| u | +0.55 | +0.3 | +0.85 | +5.7% |
| o | +0.58 | +0.2【估计：圆唇后元音，介于 /i/、/u/ 之间】 | +0.8 | +5% |
| y（ü） | +0.25 | +0.15【估计：介于 /i/、/u/】 | +0.4 | +2.7% |
| a | +0.15 | −0.1 | +0.05 | +0.3% |
| ɤ（e） | −0.08 | 0【估计】 | −0.1 | −0.5% |
| i | 0 | 0 | 0 | 0 |

结论：
1. 普通话数据支持的长度差在 **−1% 到 +6%** 之间，远小于 0.85–1.20。
2. 0.85–1.20 的依据仍是 Story, Titze & Hoffman 1998 女声 DJ 的跨元音 12.27–15.44 cm（相对均值 0.898–1.129，旧规格 §1.1【原文 V1】）两端各留约 5%。DJ 的长度是沿中线测的，包含舌位引起的中线弯曲变化，不全是唇突和喉位。
3. 因此 **0.85–1.20 作为硬边界合理**（覆盖英语女声实测 ±12% 和 1 cm 量级的个体喉位变化），但普通话预期值在 **0.97–1.08**。预测“6 个比值都不贴 0.85、1.20 两端”与此一致。若调参结果超出 0.93–1.12，应视为补偿而不是生理长度，Critic 应报告。
4. 预测机制 (1) “λ_v − λ_i ≥ +0.03”：数据估计约 +0.027，**正好在门槛附近**，判定时不宜把 0.02–0.03 当作否证。机制 (2) “λ_u ≥ λ_a + 0.03”：数据估计约 +0.054，有依据。

### 1.3 可变长度 KL 的做法

沿用旧规格 §1.2（Välimäki & Karjalainen 1994【原文 V4】；Mathur, Story & Rodriguez 2006 经 Qureshi & Ishaq 2019 转述【二手】）。本规格不新增文献。

### 2.2 段长、段数和数组

- Δ = L_ref/44 固定，fs_sim = 44·c/L_ref 不变（`sim_rate(L_ref, 44, FS_OUT)`）。
- 数组长度 N_max = ceil(44·1.20) + 1 = **54**。唇端固定在索引 N_max−1 = 53。
- 每采样有效段数 Q(t) = 44·λ(t)，M = floor(Q)，α = Q − M ∈ [0, 1)，首个激活段 k0 = N_max − M。λ ∈ [0.85, 1.20] 时 Q ∈ [37.4, 52.8]，k0 ∈ [2, 17]。
- **λ = 1 时 α 必须精确为 0**（spec_request (5)）：块级 Qb = round(44·λ_blk, 9)；逐采样插值 Q = Qb[blk] + fr·(Qb[blk+1] − Qb[blk])，两块都是 44.0 时差为 0，Q 精确为 44.0；M = floor(round(Q, 9))。

### 2.3 面积映射（控制域 44 段 → 仿真域 N_max 段）

所有控制层的运算**仍在 44 段参考域**里做，顺序不变：元音目标、g002-e06 乘性收紧 `constrict()`、关键帧插值、两级 `_lp1`、`min_area` 下限、`TB.dc_flow` 与 `TB.constriction_amp`（它们只用最小面积和面积求和，与拉伸无关）。

然后每个控制块做一次整体拉伸（旧树 `stretch_areas`）：激活段 j（距唇第 j 段，j = 0…M−1）的面积取 A44 在归一化位置 1 − (j+0.5)/Qb 处的线性插值；非激活段填 A44[0]（不参与计算，只保证块间插值时新激活段的面积有定义且 > 0）。Qb = 44 时直接复制，与参考面积逐值相同。

内核按 e07c 在块间逐采样插值全部 N_max 个面积（或至少 min(k0_blk, k0_blk+1) 到 N_max−1）。

## 3. 内核（kl_core 的改动）

### 3.1 声门端分数段（同旧规格 §2.3 与旧树）

本采样到达声门端的后行波 x = b[k0]，缓冲 z1、z2 存 x 的前 1、2 个采样，D = 2α：
```
若 D == 0：y = x                         # 显式分支，保证 λ=1 时逐位相同
若 0 < D < 1：y = (1−D)·x + D·z1
若 1 ≤ D < 2：d = D−1；y = (1−d)·z1 + d·z2
z2 ← z1；z1 ← x
u_in = ug[t]（α = 0）或 (1−α)·ug[t] + α·ug[t−1]      # 声源经分数段单程延迟 α
nf[k0] = r_g·y + u_in / Ab[k0]
```
分数段与 k0 段共用面积 Ab[k0]（分数段内没有结点）。

### 3.2 静态能量证明（含 V）【推导】

存储量：0 ≤ D < 1 时 V = Ab[k0]·D·z1²；1 ≤ D < 2 时 V = Ab[k0]·(z1² + d·z2²)。
记 A0 = Ab[k0]，g = 1 − μ。面积、α 固定，零输入：
1. 所有并联结点（含鼻腔三端口）满足 Σ A·(出射)² = Σ A·(入射)²（主线 kl.py 已有的性质）。唇端、鼻孔端只减能（r ≤ 1）。所以 E' = g²·[E − A0·x² + A0·r_g²·y² − 唇鼻损耗] ≤ g²·(E − A0·x² + A0·y²)。
2. 缓冲：D < 1 时 V' − V = A0·D·(x² − z1²)；Jensen 不等式给出 y² ≤ (1−D)x² + D·z1²，所以 V' − V ≤ A0·(x² − y²)。D ≥ 1 时 V' − V = A0·(x² + d·z1² − z1² − d·z2²) = A0·(x² − [(1−d)z1² + d·z2²]) ≤ A0·(x² − y²)。
3. 两式相加：(E' + V') − (E + V) ≤ (g² − 1)·E + (1 − g²)·A0·x² + (g²·r_g² − 1)·A0·y²。因为 A0·x² = A0·b[k0]² ≤ E，前两项之和 ≤ 0；第三项 ≤ 0。
所以 r_g ≤ 1、r_lip ≤ 1、μ ≥ 0、面积和 α 固定时，**E + V 逐采样单调不增**。
`zero_input_energy` 返回 E + V（旧树 `_frac_store` 的公式与此相同，可以照搬）。T0 的 1e-12 容差下要求 V 精确按上式计入。

### 3.3 段数变化时的状态移交（§2.4 的重写，逐采样）

M(t) 与 M(t−1) 不同时，在第 t 个采样的开头（声门端更新之前）移交。|ΔQ| 每采样 ≤ 约 0.01（见 §3.5），所以每采样最多变化 1 段；内核仍按 while 循环写，以防万一。

**伸长**（M → M+1，k0' = k0 − 1；移交前 α ≈ 1，D ≈ 2）：分数段近似一整段，缓冲中 z1 是 1 个采样前离开 k0 的后行波（还在路上，下一采样到声门），z2 是 2 个采样前离开的（这一采样到声门并反射）。对应到新整段 k0'：
```
b'[k0'] = z1
f'[k0'] = r_g·z2
P_before = A0·(z1² + d·z2²)            # 即 V；A0 = Ab[k0]，d = D−1
P_after  = Ab[k0']·(b'² + f'²)
若 P_after > P_before：b'、f' 同乘 sqrt(P_before / P_after)
z1 = z2 = 0（新 α ≈ 0，缓冲重新开始）
```
**缩短**（M → M−1，k0' = k0 + 1；移交前 α ≈ 0，移交后 α' ≈ 1）：被关闭段 k0 的两个行波变成新分数段（长度约一整段）的内容：
```
z1' = b[k0]           # 后行波，下一采样到声门
z2' = f[k0]           # 前行波；新分数段输出时会再乘一次 r_g，r_g = 1 时精确，r_g < 1 时多减一点能
P_before = Ab[k0]·(f[k0]² + b[k0]²) + V_old      # V_old = A0·D·z1² ≈ 0，直接丢弃
P_after  = Ab[k0']·(z1'² + d'·z2'²)               # d' = 2α' − 1
若 P_after > P_before：z1'、z2' 同乘 sqrt(P_before / P_after)
f[k0] = b[k0] = 0
```
推导依据【推导】：D = 2 时 y_n = z2，nf[k0'] = r_g·z2，对应旧结构中 f[k0] 经结点进入 k0'；下一采样 y = z1，对应 b[k0] 在声门反射后进入 k0'。面积相等、r_g = 1、d 取 1 时两种结构逐样本一致。

**能量**：两个方向都按 P_after ≤ P_before 裁剪，所以**移交本身不增加 E + V**。裁剪只在 Ab[k0'] ≠ Ab[k0] 或 d ≠ 1 时起作用，幅度约为相邻段面积差（e06 的 /a/ 声门端 0.30 vs 0.33，约 5%）。
与旧树的区别：旧树伸长时写入 `r_g·z1 + ug/A`（时序错一位，并重复注入声源），缩短时把前行波直接丢掉，也没有裁剪。

### 3.4 e07c 逐采样面积插值下的缓冲更新（spec_request (2) 后半）

- 内核每采样先算 Q(t)、M(t)、α(t)、k0(t)（§2.2），再插值面积 Ab，再做 §3.3 的移交（如需），再按 §3.1 用 α(t) 更新缓冲。缓冲系数逐采样变化，不再在块边界跳变。
- V 用当前采样的 Ab[k0(t)]。
- α 在 0 与 1 之间连续变化时，V 中的系数 D 每采样变化约 2|ΔQ|，V 会随之小幅变化（可正可负）。这和面积随时间变化一样，属于时变参数做功，E + V 不再严格单调。这一点不进 T0（T0 是单块、静态），由 §6 的动态检查覆盖。
- 旧树的 α 是每块常数，λ 在 20 ms 内变 0.3 时每块 ΔQ ≈ 0.13，分数延迟系数每 1 ms 跳一次，正是 1 kHz 块率的参数阶跃。这很可能是 g001-e03 高频能量升到 1.6 倍的原因之一（另一个原因是旧树的父版本 g0 还没有 e07c，面积本身就按块阶跃）【推导，未经实验分离】。

### 3.5 λ 轨迹的生成（gestures）

- `Timeline.key` 每个关键帧带 λ：元音关键帧取该元音的 λ；声母关键帧（叠在首元音上）取首元音的 λ；鼻韵尾关键帧取末元音的 λ；停顿、句首句尾取 1.0（同旧树 `cur_lam` 的做法）。
- **e07c 的静音预就位**（`render()` 中“静音帧取声母的面积函数与软腭口”那段）必须把 λ 和 A 一起复制过去，否则静音帧的面积是声母、首元音的形状，λ 却还是 1.0，长度变化就会落在有声段的开头。
- λ 与 A、Avp、ag 用**同一个**两级 `_lp1` 平滑。因此长度过渡的时间尺度与面积相同（τ = artic_tau_ms）。λ 跨度 0.35、τ = 10 ms 时，|dQ/dt| 最大约 15 段/10 ms，即每采样约 0.015 段（fs_sim ≈ 102 kHz）【推导，量级】。
- `render()` 多返回一个 lam[nf]；synth 计算 Qb = round(44·lam, 9)，再做拉伸和索引重映射（§4），然后调用 kl_core。

## 4. 索引重映射（spec_request (2)）

N_ref = 44，N_max = 54，off = N_max − 44 = 10。λ = 1 时每一项都等于“主线索引 + off”，所以逐位复现。

| 量 | 主线 | 本规格 | 锚点与理由 |
|---|---|---|---|

## 5. T0 钩子（spec_request (5)）

- `kl_run` 是 T0 使用的原签名包装（主线 kl.py 第 25–29 行）。它的签名**不变**，内部改为调用新 kl_core，并传入 k0 ≡ 0、Q ≡ 数组长度（44）、缓冲 z = 0。这样 α ≡ 0，走 §3.1 的 `D == 0` 显式分支。
- `tube_impulse_response` 一行不改：它传入 44 段数组，k0 = 0，没有填充段，没有分数段。逐采样结果与现在相同，满足 ENGINE_API.md 的“同一代码路径、理想终端”（方案 C），钩子语义不变。
- `zero_input_energy`：用 `area_a` 和 `len_ratio_a` 构造静态几何（单块，不插值）。len_ratio_a = 1.0 时 Q = 44、α = 0，与现在相同；≠ 1 时用 N_max 数组，k0 及之后的段和缓冲 z 都用种子随机初始化，返回 E + V。
- T0 的“全部取 min / max”角点：λ_a = 0.85（Q = 37.4）或 1.20（Q = 52.8，M = 52 ≤ N_max − 1 = 53），都在数组范围内。
- 实现自检（Critic 必查）：(a) 引擎在全部 λ = 1 的父版本参数下，对 opt 集和 30 句开发集的合成结果与主线逐样本相同（不只是 T0）；(b) 草稿中直接调用内核，在 α ∈ {0, 0.25, 0.5, 0.75, 0.999}、两个能量角点下，E + V 的逐采样相对上升 ≤ 1e-12。

## 6. 动态瞬态检查（spec_request (3)）

### 6.1 现有 `vowels` 序列能否覆盖 M 的增减？

`vowels` = "a1 yi1 wu1 a1 yu1 o1 e1 a1" 包含全部 6 个带 λ 的元音。相邻两个元音的 |Δλ| ≥ 1/44 ≈ 0.023 时，过渡中至少跨一次整数段。

**不够**，原因有三【推导】：
1. 父版本和热启动起点的 λ 全为 1.0，根本不跨段。是否跨段完全取决于调参结果。λ 都在 1.00 ± 0.01（即预测中的否证情形）时，这项检查什么也没测到，却会显示“通过”。
2. 即使跨段，跨的段数也取决于调参结果，不同种子之间不可比。
3. 句首、句尾和停顿的 λ = 1 → 元音 λ 的过渡发生在静音预就位期间（§3.5），点击指标只统计有声帧，测不到。

### 6.2 新增 `lensweep` 序列（写进 tools/dynamic_t0_check.py；只改 tools，不改 eval/）

- 拼音同 `vowels`："a1 yi1 wu1 a1 yu1 o1 e1 a1"。
- 参数覆盖（在给定参数文件上改写）：len_ratio_a = 0.85、len_ratio_i = 1.20、len_ratio_u = 0.85、len_ratio_v = 1.20、len_ratio_o = 1.20、len_ratio_e = 0.85。每个过渡跨约 15 段，伸长和缩短都有，覆盖整个范围。
- 对照：同一引擎、同一参数文件、全部 λ 覆盖为 1.0 的同一序列。父版本引擎没有 λ，不能作对照。
- 指标：现有 click_metric（6 kHz 高通、2 ms 帧、有声帧 max/中位数）。
- 判据：lensweep ≤ 1.5 × 全部 λ = 1 的值。1.5 沿用 Planner 对 vowels 序列的门槛。
- 不改变现有三个序列的结果：参数文件中没有 `len_ratio_*` 时跳过 lensweep，旧参数的输出与改动前逐位相同。

### 6.3 建议加的零输入动态能量检查（草稿或 tools，不进 eval/）

均匀管（面积全为 1）、无损（μ = 0，r_g = 1，r_lip = 0.995）、零输入，随机初态。λ(t) 在 0.85 与 1.20 之间以 5 Hz 正弦扫 0.5 s。要求：
- 每次 M 变化的那个采样，(E + V) 的相对跳变 ≤ 1e-12（§3.3 的裁剪保证这一点）；
- 全程 max (E+V)(t)/(E+V)(0) ≤ 1.5。长度变化会对声场做功，所以不要求单调；界取频率比 1.20/0.85 ≈ 1.41（共振能量的绝热不变量 E/ω）再放一点余量【推导，量级】。

## 8. 风险与判断（对假设本身）

本节的共振峰数值是我在草稿中用**无损链矩阵**算的：44 段，c = 350 m/s，声门闭端、唇端 p = 0，不含辐射、壁损耗和鼻腔；用 e06 的面积和 L = 15.04 cm。只能看方向和量级，不是引擎实测【推导】。

1. **/i/ 咽腔贴边不是单一长度逼出来的**。e06 /i/ 原样：F1/F2/F3 = 286/2430/3283 Hz。
   - 咽腔压到 ≤ 6.5 cm² 后：322/2323/3251，F1 升 12.6%。
   - 用整体拉伸把 F1 拉回 286，需要 λ ≈ 1.13，但这时 F2 ≈ 2045 Hz，比原来低 16%。整体拉伸对 /i/ 是错误的杠杆。
   - 只加长后腔（第 0–21 段）2 cm：F1 才回到 290，F2 也降到 2019。
   - 相反，长度不变、咽腔 ≤ 6.5、只把第 28–40 段（硬腭收紧区）乘 0.75：得到 292/2403/3342，与原样相差 ≤ 2%。这时 /i/ 罚项为 0（tools/plausibility.py：总罚项 0.0054 → 0.0035）。

   也就是说，固定长度下**存在**不贴边、共振峰几乎不变的 /i/ 形状。/i/ 贴边更可能来自优化器的参数化（6 个全局余弦模态很难做到“只收紧前腔、不撑大后腔”）或局部最优，而不是“全句只有一个长度”。预测“/i/ 贴边 13 → 0–4”即使实现，也不能归功于 len_ratio_i。Critic 应同时看 len_ratio_i 是否离开 1.0。

   另外，Planner 的理由“/i/ 可以靠降喉加长后腔”没有普通话或其他语言数据支持：德语 MRI 中 /i/ 的喉位比 /u/ 高约 3 mm，只比 /a/ 低约 1 mm（Hoole 等 2020【原文】）。DJ 的 /i/ 比 /ɑ/ 长，来自英语单被试的中线长度。

2. **/ü/ 有支持**。e06 /ü/ 唇口 0.065 → 0.10 cm²，F1 +2.4%、F3 +2.2%；λ_v = 1.02 即可基本抵消（247/2191/2964 vs 原样 246/2229/2957）【推导】。所需的 +2% 与 §1.2 的数据估计（ü 比 i 长约 2.7%）一致。这是本假设最可能成立的部分。

3. **/a/ 方向与 DJ 相反**。/a/ 面积压到 ≤ 6.5 后 F2、F3 升约 3%，需要 λ_a ≈ 1.03 或更长才能抵消；DJ 的 /ɑ/ 比均值短（0.99），普通话数据估计约 +0.3%。若调参得到 λ_a > 1.05，应视为补偿，不是生理长度。预测中 /a/ 一项把握低，与此一致。

4. **整体拉伸 ≠ 唇突**。唇突在唇端加一段细管，喉位下降在声门端加长会厌喉段；整体拉伸把增量均摊到全长。对 /u/、/ü/ 这类唇口很小的元音，二者的声学效果不同。可选扩展（不在本假设内）：分成“唇端长度”和“声门端长度”两个参数（旧规格 §2.2）。
