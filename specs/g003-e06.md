**对低阶共振峰的影响**：
- 数值模型（KH），把旁支从唇端移到实际位置（**距声门端 2 cm**）：F1 降约 11%（/a/）和 4%（/i/）。原文还说 F1 随结点后移单调下降，F2、F3 的变化取决于旁支与所在部位的容积比【原文 p.18】。注意：这是相对“旁支接在唇端”，不是相对“没有旁支”。

- 原文的数值模型把左右两侧作为**一对**旁支，开口处的辐射系数取 0.75【原文 p.16】。

## 3. 一根还是两根（spec_request (3)）

- 一维理论中，两根长度相同的闭端管并联，与一根面积为两者之和的管完全等价【推导】。
- 实测左右差异小：Table II 单侧零点左右只差 0.3–1.8%；Table I 容积左右差 ≤ 20%，RY 约 3–20%【原文】。
- 两侧同时存在时，实测零点比单侧高约 5%【原文 Table II】，这是三维开口效应，一维等效管表达不了。本规格的管长按两侧都在的自然语音零点（Fig. 13）定标，所以合并后的零点频率仍然对。
- Takemoto 等 2013【二手】指出左右各有一个凹陷，并会相互作用。用一根管会少一个凹陷，但两侧零点只差几十 Hz，在 22.05 kHz 输出、2 ms 分析帧下分辨不出。
- **结论：用一根合并管。** 每增加一根管就多 2 个固定参数和一个结点，收益低于 T1 的分辨率。

## 4. 内核：三端口结点、闭端与能量（spec_request (4)）

照搬主线鼻腔结点（kl.py 第 80–85 行；fix01 的“旁支第 0 段面积就是耦合面积”写法）。

**状态**：旁支 n_p 段，行波 fp[k]、bp[k]（k = 0 为结点侧），每段面积都是 A_p（均匀管）。

**每采样**：
```
口腔结点 k == kp（A_p > 0 时）：
    pj = 2·(a1·f[kp] + a2·b[kp+1] + A_p·bp[0]) / (a1 + a2 + A_p)
    nf[kp+1] = pj − b[kp+1]；nb_[kp] = pj − f[kp]；nfp[0] = pj − bp[0]
旁支内部结点（面积相等，即纯延迟）：nfp[k+1] = fp[k]；nbp[k] = bp[k+1]
闭端（刚性，压力波反射 +1）：nbp[n_p−1] = fp[n_p−1]
推进：fp = g·nfp；bp = g·nbp（与主声道同一个壁损耗 g = 1 − μ）
能量：E += A_p·Σ_k (fp[k]² + bp[k]²)
```

**能量证明**【推导】：
- 三端口并联结点 Σ A_i·(p_out)² = Σ A_i·(p_in)²。证明与主线鼻腔结点相同：pJ = 2·Σ A_i p_i^in / Σ A_i，Σ A_i (pJ − p_i)² = pJ²·Σ A_i − 2pJ·Σ A_i p_i + Σ A_i p_i² = Σ A_i p_i²。
- 旁支内部是纯延迟，闭端反射 |+1| = 1，都不改变 A_p·(f² + b²) 之和。
- 壁损耗 g ≤ 1 只减能。
- 因此 A_p 固定、r_g ≤ 1、r_lip ≤ 1、μ ≥ 0 时，E（含旁支）逐采样单调不增。旁支是静态几何，不随时间开合，所以没有 fix01b 那种“关闭时积累压力、开启时释放”的问题。

**A_p = 0 时逐位复现父版本**：内核用显式分支——A_p == 0 时走主线原来的两端口代码，旁支状态不更新、不计入能量。不要依赖“a3 = 0 时公式退化”。数值上 0·bp 与 a1 + a2 + 0.0 通常确实精确退化，但 −0.0 和 bp 中的非有限值会破坏逐位相同。

**`kl_run`（T0 包装）签名不变**，内部传 A_p = 0、n_p = 1（只是占位）。

## 5. T0 钩子（spec_request (5)）

- `tube_impulse_response`：一行不改。kl_run 传 A_p = 0，与现在逐采样相同。
- 是否符合 ENGINE_API.md 方案 C 的“同一代码路径、理想终端”：
  - 代码路径：同一个 kl_core，同一套散射与延迟。旁支只是一个可选的结点分支，与软腭口 A_vp = 0 时鼻腔不起作用（现在的 T0 就是这样调用）完全同类。
  - 钩子语义：输入只有 area_cm2 和 length_cm，描述的是一根无分支的管子；方案 C 要求“关闭辐射阻抗、末端修正和可屈服声壁”，只测散射与延迟本身。旁支是一种几何，不是终端条件，T0 的均匀管里本来就不该有它。
  - 结论：符合，钩子语义不变。若在 T0 中接上旁支，均匀管会在 5.1 kHz 出现零点并压低低阶共振峰，T0 的理论值就失效了。这正是 g001-e02 的教训（不得改变钩子的含义）。
- `zero_input_energy`：**必须带上参数文件中的 A_p**，旁支状态也用种子随机初始化，能量含旁支。它检验的是“该参数下声道配置的稳定性”，旁支是配置的一部分。A_p 由参数文件给出，不随 T0 改变。
- T0 角点：A_p 取 min（0）时退化为父版本；取 max（2.5）时只是更大的无损旁支，§4 的证明照样成立。

## 6. 依赖：连续化工具 `anneal_to`（spec_request (6)）

### 6.1 为什么不能固定尺寸直接接入【推导】

用 §8 同样的草稿链矩阵模型，把 A_p = 1.2、5 段、结点 4 直接接到 e06 面积上（变化量相对无旁支）：

| 元音 | F1 | F2 | F3 |
|---|---|---|---|
| a | −20.2% | −19.7% | −3.9% |
| o | −8.9% | −2.9% | −7.9% |
| e | −12.5% | −0.6% | −0.2% |
| i | −1.7% | −2.5% | −3.9% |
| u | −7.5% | −1.2% | −5.0% |
| ü | −7.3% | **−25.3%** | −2.2% |

/a/ 的 F1、F2 和 /ü/ 的 F2 变化达 20–25%。原因是 e06 的 /a/、/ü/ 会厌喉至下咽段很细（第 0–4 段只有 0.6 cm³），2 cm³ 的旁支相对很大。父版本 T1 = 0.016；这样的扰动会把起点推到远离当前最优的地方，与 g002-e04 中 κ_rad = 0.85 使 T1 从 0.016 变到 0.048 是同一类情况（Critic 已据此诊断“热启动陷阱”）。**旁支不是小扰动，需要连续化。**

（这一结论来自理想化模型：无损、无辐射、均匀旁支。量级可信，具体百分比不可信。实现后的起点校验 §7 会给出引擎上的真实值。）

### 6.2 `anneal_to` 约定（供 tools/optimize.py 实现）

1. **声明**：schema 条目写 `"anneal_to": <目标值>`。这个条目**不得**带 `tune`，也不进 TARGETS，也就是不进搜索空间，优化器无法把它调回父版本值。父版本值 p0 取父参数文件中的值；父文件中没有时取 schema 的 `default`，此处为 0.0。目标值 p1 必须在 [min, max] 内。
2. **日程按代计**（同一代内取值相同，CMA-ES 的一次 tell 只看一个目标函数）。每个种子预算 B（本实验 B = 150），种群 pop。可分模式中 pop = 8，可用代数 G = floor((B − 1)/pop) = 18。令 Gr = floor(G/2) = 9。
   - 第 g 代（g = 0…G−1）的取值：p(g) = p0 + (p1 − p0)·min(1, (g+1)/Gr)。第 0–8 代线性升，第 8 代刚好到 p1；第 9–17 代固定在 p1。
   - “前一半”指第 0 到 Gr−1 代，“后一半”指第 Gr 到 G−1 代。第 Gr−1 代虽然已到 p1，但属于前一半，**不参与选最优**，以保持两半对称、事先固定。
   - 联合模式（joint）同理，G 按该模式实际的 popsize 计算。
3. **起点评估**：现有代码第一次评估父版本值（f0），并在最后 `if f0 <= bf` 时回退到父版本。有 anneal_to 参数时：
   - f0 改为**父版本的其余参数 + p1**，作为“起点校验”值记录（`start_objective_at_target`）。它占预算中原来的那 1 次，并且**参与**选最优（它的取值就是 p1）。
   - 取消回退到“父版本 + p0”。最终结果只能从取值为 p1 的评估中选：f0 加后一半各代。
4. **只在固定阶段选最优**：best 只在 p = p1 的评估中更新。trace 照常记录各代最优，但要另记每代的 p(g)，便于 Critic 看出切换点。
5. **σ 与协方差**：切换点（第 Gr 代开始）**不重置** σ，不重置协方差、进化路径和步长控制。这条事先固定，不随结果调整。理由【推导；未找到专门针对“缓慢变化目标、CMA-ES 是否重置”的文献，未核实】：
   - 每代目标只变化总扰动的 1/9；CMA-ES 的步长控制（累积路径长度）会自然适应这种缓慢漂移。
   - 重置 σ 等于在后一半重新探索，会把固定阶段 72 次评估中的一部分浪费在大步长上。
   - 事先固定可以避免研究者自由度。
6. **多种子（提案 002-A）**：每个种子各自独立执行上述日程；中位数按各种子的“固定阶段最优”取。3 种子 × 150、热启动、取中位数，都不变。
7. **写回**：输出参数文件中该参数的值写 p1。`optimizer` 字段增加 `anneal: {name, p0, p1, Gr, G}` 与 `start_objective_at_target`。
8. **对照组逐位不变**（Critic 必查）：schema 中没有任何 `anneal_to` 条目时，代码路径必须与改动前完全相同。对 e06 参数用同一种子跑一次，输出 JSON（除 `wall_min`）逐字节相同。
9. **与 002-A 的关系**：起点仍是父版本的全部可调参数，只是被连续化的那一个固定参数在前一半逐步从 p0 移到 p1。“新参数默认须复现父版本”由 schema default = 0.0 保证：直接用默认值合成，与父版本逐位相同。

## 8. 对假设本身的判断

本节数值用草稿中的**无损链矩阵**计算：44 段，c = 350 m/s，声门闭端、唇端 p = 0，无辐射、无壁损耗；旁支为闭端均匀管，输入导纳 j·A_p·tan(k·l_p)。用 e06 的面积和 L = 15.04 cm。只能看方向和量级【推导】。

1. **旁支补偿不了 /i/ 的咽腔贴边（主要机制站不住）**。
   - /i/ 的 F1 只降 1.7%，比 Planner 的 2–6% 下限还低。
   - e06 /i/ 的后腔（第 0–21 段）约 49 cm³，梨状窝只有 2 cm³（RY），约 4%；按 Helmholtz F1 ∝ V^(−1/2)，降幅约 2%，与计算一致。
   - /i/ 咽腔从 9 压到 6.5 cm²，相当于后腔少约 12 cm³，F1 从 286 升到 322 Hz。加上旁支后只回到 315 Hz，补回了 36 Hz 中的 7 Hz。
   - Planner 在 rationale 中已经估计“梨状窝几 cm³ vs 多出来的 15–20 cm³”；按女性实测容积 2.0–2.1 cm³，差距比他估计的还大。预测“/i/ 贴边段数 13 → 6–11”很可能不成立，否证条件“/i/ 贴边仍 ≥ 12”很可能触发。
2. **起点校验预测偏乐观**。/u/、/ü/ 的 F1 降 7.3–7.5%，超过 2–6% 的上限；/a/ 的 F1、F2 降约 20%，/ü/ 的 F2 降 25%。父版本 + 满值旁支的 T1 可能明显高于 0.019–0.030。
3. **/a/ 会更糟**（与 Planner 判断一致）。/a/ 的 F1 降 20%，优化器要把 /a/ 张得更开来补回，/a/ 贴边可能加重。
4. **值得做的部分**：(a) 5.1 kHz 零点是有文献支持、可直接检验的频谱细节，对 T4 或听感可能有用；(b) 在 anneal_to 下，面积有机会与真实的下咽结构协同调整。若本实验的目的是“检验 /i/ 贴边是否源于缺少下咽容积”，按上面的估算，预期答案是“否”。实验仍可作为该解释的否证来做，但不应期望改善 M1。
5. **另一种解释**（见 specs/g003-e01.md §8）：同一草稿模型中，长度不变、无旁支，只把 /i/ 咽腔压到 6.5、硬腭收紧区（第 28–40 段）乘 0.75，共振峰与原样相差 ≤ 2%，/i/ 罚项清零。/i/ 贴边更可能来自优化器的参数化（6 个全局余弦模态）或局部最优，不是声道拓扑缺件。
