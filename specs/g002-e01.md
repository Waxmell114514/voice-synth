选 Story 2018 女性版的理由：
1. 输出直接是面积函数，44 段、声门→唇，与引擎的数组约定完全一致，不需要中矢状面→面积的转换【已核实 P2：作者明确指出这一点是优点】。

## 1. 方程

### 1.1 Tier I：元音底座（Story 2005 Eq.3；Story 2018 Eq.1）

```
V(i) = (π/4) · [ Ω(i) + q1·φ1(i) + q2·φ2(i) ]² ,   i = 1..44（1=紧贴声门上方，44=唇端）
```
- Ω(i)：中性直径函数（cm）。q1 = q2 = 0 时得到近似等间距共振峰的中性管【已核实 P1】。
- φ1、φ2：前两个主成分（“模态”），单位 cm/单位系数【已核实 P1、P2】。
- 方括号里的量是**等效直径**，平方后乘 π/4 得到面积【已核实 P1】。实现时须先把方括号里的值截断到 ≥ 0 再平方，否则负直径平方后会变成正面积【推导】。

### 1.2 Tier II：收紧叠加（Story 2005 Eq.1、5–9）

```
A(i) = V(i) · Π_k C_k(i)                                         (Eq.1)
C(i) = 1 − m_c · d_c · exp( −ln16 · ((i − l_c)/r_b)² ) ,  i < l_c
     = 1 − m_c · d_c · exp( −ln16 · ((i − l_c)/r_f)² ) ,  i ≥ l_c     (Eq.5)
d_c  = 1 − a_c / V(l_c)                                           (Eq.6)
r_f  = s_c·r_c/(1+s_c) ,  r_b = r_c/(1+s_c)                       (Eq.7、8)
C(i) = max(C(i), 0)                                               (Eq.9)
```
- l_c：收紧中心段号；a_c：最窄处面积（cm²）；r_c：C = 0.5 两点之间的距离（段数），即半高全宽；s_c：偏斜（1 = 对称，<1 时更多范围落在唇侧）；m_c：激活量。m_c = 1 时恰好在 l_c 处达到 a_c；m_c > 1 时把闭塞“摊开”到几段【全部已核实 P1】。
- 注意：Story 2005 原文 Eq.5 中 r_b 用于 i < l_c，r_f 用于 i > l_c；i = l_c 时两式相同【已核实 P1】。

### 1.3 Tier III：长度扰动（Story 2005 Eq.10–13）——**引擎暂不支持，只作记录**

```
L(i) = Δ·α(i)·β(i)
α(i) = 1 + p_g·exp(−K((i−l_g)/(2r_g))²) / (Δ·Σ_i exp(−K((i−l_g)/(2r_g))²))   （喉位：p_g < 0 为降喉，单位 cm）
β(i) = 同式，参数 p_m, l_m, r_m（唇突：p_m > 0 为突唇，单位 cm）
K = 2·ln(10000)；通常 l_g = 1，l_m = 44
```
【已核实 P1 Eq.10–13】。Story 2005 原文演示 p_g = −1 cm，p_m = +2 cm，r_g = r_m = 8 段【已核实 P1】。
注意：原文写的是 p_g < 0 为“降喉”。但按公式，p_g < 0 会**缩短**声门端；Fig.6 也把 p_g = −1 描述为“1 cm reduction in length”。也就是说，原文的“lowering(p_g<0)”与公式中长度变化的方向相反。实现时**以公式为准**：p_g > 0 表示加长（降喉）【推导；措辞矛盾为原文问题】。

### 1.4 Tier IV：鼻腔耦合
单参数 a_np（腭咽口面积），与现有 `velum_open_area` / A_vp 相同，本规格不改【已核实 P1】。

## 5. 长度、唇突、喉位如何映射到引擎（单一 tract_length_cm、固定 44 段）

1. **模型本身就是定长的**。Story 2018 对所有元音都用同一个 L(i) = 0.353 cm。理由是 CT 数据来自静息呼吸，没有逐元音长度信息【已核实 P2 第 II 节】。因此，模型与引擎“单一长度”的现状一致，可以直接用。
2. **唇突（Tier III 的 p_m）**：引擎没有逐元音长度，暂时**由唇口面积吸收**。一段长 ℓ、面积 A 的唇管加长 p 之后，低频声质量 ρ(ℓ+p)/A 与面积为 A·ℓ/(ℓ+p) 的原长管相同【推导】。所以 `lip_area` 的下限放到 0.08 cm²，即已包含这一等效。缺陷：它只等效声质量，不等效容积和 F3 处的长度效应。第 4 节 [u] 的残差（F2 约 +14%）就是证据。**标记为已知误差**。
3. **喉位（Tier III 的 p_g）**：只能通过全局 `tract_length_cm` 体现，不能逐元音变化。**标记**。
4. **后续**：引擎支持分数延迟或可变段长后（g001-e03；Mathur, Story & Rodriguez 2006【未核实，只经转述】），直接实现 Tier III：每个元音加 `lip_prot_cm`（0–1.5 cm，圆唇元音）和 `larynx_cm`（−1 – +1 cm）。范围【未核实】，参照 Story 2005 演示值 p_m = +2、p_g = −1【已核实 P1】。
5. **与 g001-e01（非均匀轴向变形）的关系**：女性版模态**已经**按女性解剖标志点做过轴向变形和截面缩放。若同时启用 e01 的 warp，女性化就做了两次。**g002 分支中 e01 的 warp 必须置为恒等**（ρ_e = ρ_p = 1）【推导】。g001-e03 的整体拉伸与本模型正交，可以叠加。
6. **鼻腔耦合位置**：Story 2005 男性在第 22 段（距声门 8.7 cm）【已核实 P1】。女性版 HPSP 在约第 25 段，腭咽口在其后方。现有 `velum_pos_frac` 默认 0.5（约第 22 段）可以保留【推导】。

## 6. 辅音收紧如何与模型组合

现行 `gestures.constrict()`：`tgt = base·(1−m) + area·m`，m 为标准差 `cwidth`（段）的高斯，再与 base 取 min。
Story 2005 的 Tier II（Eq.1、5、6）在 m_c = 1 时可以改写为 `A = V·(1−g) + a_c·(V(i)/V(l_c))·g`，g = exp(−ln16·((i−l_c)/r)²)。两者只差一个因子 V(i)/V(l_c)：Story 的写法让收紧两侧保留元音形状的比例【推导】。

建议：
1. **最小改动**（g002-e01 就做）：元音目标改由模型生成，`constrict()` 保持不变，叠加在生成的元音面积上。高斯宽度换算：Story 的 r_c 是半高全宽，σ = r_c / (2·√(2 ln2)) = r_c / 2.355【推导】。
2. **推荐改动**（可与 1 同时做，也可放到下一代）：把 `constrict()` 换成 Story Eq.5–9（乘法、带 s_c 和 m_c）。`closure_area` 改成 a_c = 0 加 m_c = 1.1–2.0 摊开闭塞，与 Story 的闭塞一致【已核实 P1 Table I：所有闭塞辅音 m_c > 1】。
3. 部位初值可以直接借 Story 2005 Table I（男性段号；女性版段号是同一归一化位置）【已核实数值 P1，迁移到女性版为推导】：

## 9. 主要风险

1. 女性版是“男性模态 + 解剖变形”，不是女性发音数据；女性特有的元音形状差异不在模态里【已核实 P2】。可选的改进是用 DJ 的 10 个元音（P3 Table II）按 Story 2018 第 II 节的步骤（3 点平滑、首段设 0.5、转直径、PCA）自行求女性模态【推导；属于“文献解剖数据”的派生，符合 CONSTRAINTS 第 4 条】。
2. 两个模态不足以描述普通话后圆唇元音，需要舌背收紧加唇口；在没有 Tier III 时，[u] 的 F2 仍偏高约 10–15%【推导】。
3. 第 2、4 节的共振峰全部来自我的简化声学模型（壁参数【未核实】）。引擎的 KL 模型带集总损耗，数值会不同。初值只能当起点。
4. lip_area 与 q2 都控制唇区，可辨识性较差；优化器可能在两者之间漂移。建议对 q 偏离英语锚点加小罚项【推导】。
5. Story 2005 Tier III 中 p_g 的正负号，原文文字与公式相反（1.3 节）。
