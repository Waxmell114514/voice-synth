## 0. 结论摘要

1. **κ_rad = 0.80**，跑之前定死（§1）。这是声道文献中用于嘴唇末端修正的惯例 Δl = 0.8·√(A/π)（Laine 1983 原文；他的实验把管口装在半径 9 cm 的球面挡板上，代表人头）。它在无挡板 0.61 与有挡板 0.85 之间，靠近有挡板一端，与「口在球面上、a/R ≤ 0.15」的几何一致。
2. **日程按代计**（§2）：每个种子 150 次预算中，可分模式实际评估 145 次（1 次父版本 + 18 代 × 8）。前 9 代 κ 线性上升（0.08 → 0.72，每代 +0.08，同一代内 κ 相同），后 9 代固定为 0.80。最优解只从后 9 代（72 次评估）中选。这是在代粒度下最接近 75/75 的分法：前段 73 次（含父版本），后段 72 次。
3. **切换点不重置 σ 和协方差**，事先定死（§2.4）。理由是切换点上目标函数的变化与上升阶段任意相邻两代之间一样（κ 都是 +0.08），没有理由单独对待。
4. **与 002-A 相容**（§3）：3 种子 × 150、热启动、取中位数都不变；rad_kappa 的 schema 默认值仍为 0；第 1 次评估逐位复现 e06；对照组（没有 anneal_to）逐位不变。有两处要 orchestrator 知情：一是最终参数中 rad_kappa 是一个未调参的非默认固定值；二是固定阶段的有效预算只有对照组的一半。
5. 本代不加 κ_bl（§4）。草稿中的预计算（§6）显示，κ_rad = 0.8 对 e06 的面积会把 /a/ 的 F1 从 1023 Hz 压到 892 Hz（−12.8%），B1 反而**下降**约 15 Hz。

## 1. κ_rad 的固定值（spec_request 1）

### 1.1 内核中 κ 的含义
e04 内核中 τ = κ_rad·a/c，a = √(A_lip/π)。低频时 Z_r ≈ s·L_r，L_r/Z_c = τ，相当于把管子加长 δ = κ_rad·a。所以 **κ_rad 就是「末端修正长度 / 唇口半径」**【推导，见 specs/g002-e04.md §1.2；读了 e04 的 kl.py 文件头】。

### 1.2 候选值

| 情形 | δ/a | 出处 | 标记 |
|---|---|---|---|
| 无挡板圆管 | 0.6133（常写作 0.61） | Levine & Schwinger 1948 | 0.61【二手】（检索摘要与 Rose-Hulman 讲义一致）；0.6133【未核实】 |
| 无限大挡板中的活塞，低频极限 | 8/(3π) = 0.8488 | 由 Flanagan 1972 的 L_r = 8a/(3πc)·Z_c 推出 | 式子【二手】（Picone 讲义、arXiv 2511.00428 两份一致，见 specs/g002-e04.md）；Flanagan 原书【未核实】 |
| 有法兰的圆管 | 约 0.82 | Norris & Sheng 1989 等 | 【未核实】（凭记忆） |
| **声道文献中嘴唇的末端修正（Fant 的高极点校正惯例）** | **0.8** | Laine 1983：「有效长度 l′ = l + Δl，Δl = 0.8·√(A₀/π)，A₀ 为口唇开口面积」；他的实验在半径 9 cm 的**球面挡板**上测，参考模型的唇辐射用 Morse & Ingard 1968 的「球中活塞」级数精确计算，与实测吻合到约 7 kHz | 【已核实 R1】；0.8 源自 Fant 1959/1960【已核实 R1，二手】 |
| 球中活塞（人头），Stevens 1998 *Acoustic Phonetics* 第 1 章 | 介于 0.61 与 0.85 之间 | Stevens 1998 | 【找不到】：没拿到书，检索到的论文也没有转述数值 |
| 普通话或中国人头部的专门数据 | — | — | 【找不到】 |

### 1.3 选 0.80 的理由
1. 这是唯一在本次读到的原文中、**明确用于人嘴**的数值（R1）。R1 的实验几何（球面挡板，R = 9 cm）也正是「人头」的近似。
2. 几何上：唇口半径 a ≤ 1.3 cm（/a/ 的 4.3–5 cm²），头半径约 9 cm，a/R ≤ 0.15。活塞周围的近场看到的几乎是平面挡板，所以惯量应接近、但略低于无限挡板值 0.85【推导；Morse & Ingard 的级数我没算，此为定性判断】。
3. 0.80 与 0.85 的差别很小：/a/ 唇口 4.3 cm² 时 a = 1.17 cm，δ 分别为 0.94 cm 和 0.99 cm，相差 0.06 cm，约为声道长度的 0.4%，共振峰频率的差别也在这个量级，小于 T1 的调参噪声【推导】。所以选值的风险很低，关键是事先定死。
4. **不一致之处**（如实说明，本代不处理）：e04 内核的辐射电阻 ρ_r = 128/(9π²) 是无限挡板活塞的高频值，κ 改成球面值并没有同时改电阻。低频时，球面上的活塞向全空间辐射，辐射电阻约为挡板情形的一半【未核实，物理常识】。内核已签署，本代不动 ρ_r。

### 1.4 起点校验的修正
plan 中的起点校验（「父版本参数在 κ = 0.85 下的 opt 集 T1 ≈ 0.048，范围 0.044–0.052」）来自 Critic 用 **e04** 的调参结果测的值。本实验用 **e06** 的参数，κ = 0.80。我估计 T1 落在 0.042–0.050（估计：δ 小 6%，频偏也相应小一些）。Implementer 在开跑前测一次（opt 集，不占配额），把结果写进报告。这个值不在 0.040–0.055 之内时先停下来问 Critic。

## 2. 连续化日程（spec_request 2）

### 2.1 schema 写法
```json
{"name": "rad_kappa", ..., "min": 0.0, "max": 1.0, "default": 0.0, "anneal_to": 0.80}
```
- 去掉 `"tune": ["M1"]`。工具在启动时断言：`anneal_to` 与 `tune` 不能同时出现，`anneal_to` 必须在 [min, max] 内，参数必须是标量。
- `default` 保持 0（002-A：新参数默认复现父版本；T0 钩子 `tube_impulse_response` 传的是字面常数 0，本来就不读默认值）。

### 2.2 日程的精确定义（按代，不按评估序号）
可分模式（M1 默认）每个种子的预算为 B = 450 / 3 = 150。现在的代码先评估父版本 1 次，再调用 `separable_m1(budget − 1 = 149)`，循环条件是 `n + 8 ≤ 149`，所以共 G = ⌊149/8⌋ = 18 代，评估 1 + 144 = 145 次，最后 5 次预算不用【推导：读了 tools/optimize.py】。对照组也是这样，本实验不改。

```
G       = ⌊(B − 1) / popsize⌋          （可分模式：18）
G_ramp  = ⌊G / 2⌋                       （9）
κ(g)    = κ_T · (g + 1) / (G_ramp + 1)    当 g < G_ramp（g = 0..8：0.08, 0.16, …, 0.72）
κ(g)    = κ_T                            当 g ≥ G_ramp（g = 9..17：0.80）
父版本评估（第 1 次）：κ = 父版本值（e06 无此参数 → schema 默认 0 → 内核旁路，逐位复现 e06）
```

| 阶段 | 代 g | κ | 评估序号 n | 次数 |
|---|---|---|---|---|
| 父版本 | — | 0 | 1 | 1 |
| 上升 | 0–8 | 0.08·(g+1) | 2–73 | 72 |
| 固定 | 9–17 | 0.80 | 74–145 | 72 |

- **同一代的 8 个个体用同一个 κ**。CMA-ES 只用代内排序更新分布，代内如果 κ 不同，排序就混入了 κ 的差别。按评估序号做「每次线性」会让同一代跨两个 κ 值。
- κ(g) 在 g = G_ramp 处与上升段的线性外推连续：上升最后一步 0.72，接下来 0.80，步长都是 0.08，**切换点上没有跳变**。
- 「前 75 次上升、后 75 次固定」在代粒度下做不到：每代 8 次，75 不是 8 的倍数，而且实际只评估 145 次。上表 73/72 是最接近的分法。改成真正用满 150 次，会改变对照组的代码路径，违反 §3 的「对照组逐位不变」，所以不改。
- 联合模式（`--mode joint`）用同一公式，popsize 取 CMA 的默认值，G 按同样的方法算。本实验用可分模式。

### 2.3 选解规则
- 每个种子的 best 只在 g ≥ G_ramp（固定阶段）的评估中取。
- **关掉 `if f0 <= bf: 取父版本` 这条回退**：父版本是 κ = 0，不是目标值，不能作为解。如果固定阶段的 72 次全都比父版本差，照样输出固定阶段最好的那次，并在报告中注明。
- 输出 JSON 的 `optimizer` 中增加：`anneal: {"rad_kappa": {"to": 0.80, "schedule": [每代的 κ], "G_ramp": 9}}`、`start_objective`（父版本，κ = 0）、`first_fixed_gen_best`（g = 9 的代内最好值）、`best_at_eval`（应 ≥ 74），以及每代结束时各块的 σ（`sigma_trace`，见 §2.4）。
- 写出的 `values` 中 rad_kappa = 0.80（来自被选中的那次评估）。
- 多种子取中位数：仍按各种子的 best_objective 排序，代码不改。

### 2.4 切换点是否重置 σ / 协方差：**不重置**（事先固定）
理由：
1. 切换点上的目标变化与上升段任意相邻两代之间相同（κ 都是 +0.08），没有不连续，所以没有理由单独在这一代重置【推导】。
2. 重置 σ 等于放弃 9 代学到的步长和协方差，固定阶段只有 9 代，重新探索的代价太大【推导】。
3. 文献：Arnold & Beyer 研究过 CSA 步长自适应在「最优点匀速移动」下的跟踪行为，结论是 CSA 不能自动得到最优跟踪步长，但不发散【未核实：凭记忆，Arnold, D. V. & Beyer, H.-G., Evolutionary Computation 2006 前后，原文没读】。我没找到专门讨论「缓慢变化的目标中途是否要重置 CMA」的文献，所以**不重置是事先定死的选择，不是有文献支持的结论**。
4. 用来事后判断的诊断（只记录，不据此改规则）：`sigma_trace` 中，若某块在 g = 8 时 σ < 0.2 × 初值 0.15，说明上升阶段已经收敛到「跟踪」状态，固定阶段可探索的余地小。报告时写出来。

## 4. 本代不加 κ_bl（spec_request 4）
- 确认不加。理由：Critic 实测 κ_bl 对 T1 几乎没有影响（0 → 1 时 0.01474 → 0.01459）；而且 g003-e02 的草稿显示，wall_loss = 0.01 时，κ_bl = 1 只让 B1 变化 2.7–8.1%（specs/g003-e02.md §6）。
- `bl_loss_kappa` 不在本分支（e04 树基于 e00p，没有 e03 的内核），所以不存在「误调」的问题。

## 5. 实现与验收

### 5.1 合并
- e04 分支改了 kl.py、synth.py、t0_api.py、schema；e06 改了 gestures.py、schema。只有 schema.json 会冲突：两边各自新增的条目都保留，并按 e06 的附带要求把 cwidth_* 标为 inactive。
- 合并后用 e06 的参数（rad_kappa = 0）合成，与主线逐样本相同。

### 5.2 optimize.py 的改动范围
- 读 schema 时收集 `anneal = {name: to}`。**若 anneal 为空，代码路径与改动前完全相同**：不多抽随机数，不改 CMA 的种子、popsize、σ，`decode` 不变，输出 JSON 的字段也不变。
- 在 `separable_m1` 每代 `ask()` 之前，按 §2.2 算出 κ(g)，把这一代所有 `decode` 出来的 `v[name]` 覆盖为 κ(g)。annealed 参数不在 x 中，CMA 看不到它。
- 多种子模式下，子进程原样传参，日程只依赖代序号，与种子无关。

### 5.3 开跑前检查（全部通过才开始调参）
1. 对照组逐位不变：`--parent params/g002-e06.json --seeds 1,2,3`，用改前和改后的 optimize.py 各跑一次（schema 中没有 anneal_to），三个种子的 seed*.json 中 values 与 trace 逐字节相同。如果嫌贵，可以用 `--budget 33`（每种子 11 次 = 1 + 1 代）比对，再加一次全预算的种子 1。
2. κ = 0 逐位复现：e06 参数 + 本分支引擎，与主线 wav 逐样本相同。
3. **κ > 0 的动态检查**：e06 参数 + rad_kappa = 0.80，跑 `tools/dynamic_t0_check.py`，以 e06 为父版本。g002-e04 的 dynamic.json 是在 κ = 0（旁路）下测的【已核实：reports/evals/g002-e04.dynamic.json 的 clicks 与对照组相同】，所以 WDF 在合成语音（尤其是 velum 序列中 m 的唇闭合）里**从来没有在开启状态下测过**。咔哒比须满足 plan 的 vowels ≤ 1.3 × 父版本、velum ≤ 1.3 × 父版本；不满足就先停下来问 Critic。
4. 起点 T1：见 §1.4。

### 5.4 旁路阈值与上升段
- K = 2N·κ·a/L。上升第一步 κ = 0.08 时，唇口为 min_area = 0.005 cm²（a = 0.040 cm）、L = 15.04 cm，K = 0.019，高于旁路阈值 1e-3，辐射开启。只有 A_lip < 1.3×10⁻⁵ cm² 才会走旁路，而 min_area 远大于此【推导】。所以上升段不会在旁路和开启之间来回切换。

解读：
1. 频率：κ = 0.8 时 /a/ F1 −12.8%、F2 −4.2%，/i/ F2 −2.4%，/u/ F2 −4.4%。这与 Critic 测到的 T1 从 0.016 变到 0.048 一致。

## 7. 对假设的意见（站不住或有风险的地方）

1. **共用块问题没有解决**：tract_length_cm 仍在可分优化器的共用块里，靠总误差驱动，而 Critic 专项判断 2 说的正是「共用标量和逐元音面积无法协同」。连续化只保证 κ 不会被关掉，不保证长度会去抵消末端修正。所以「tract_length 降到 14.2–14.8」这条预测把握不大。末端修正与唇口面积有关（/a/ 约 0.94 cm，/u/ 约 0.14 cm），统一缩短长度本来也只能部分抵消，更可能的是各元音自己的面积去吸收。
2. **固定阶段预算减半**：只有 72 次评估在目标 κ 下。如果 T1 停在 0.025–0.030，分不清是「热启动陷阱」还是「预算不够」。plan 的证伪条件「T1 ≥ 0.030 → 改冷启动」应补一句：同时看 trace 在 g = 9–17 是否仍在下降，若仍在下降，归因为预算不够。
3. B3 预测（+30–150 Hz）按 §6 很可能落空；B1 的方向与 plan 的直觉相反。这两条都应在跑之前改写，或标为预计落空。
4. ρ_r 用的是无限挡板值，κ 用的是球面惯例值，两者不配套（§1.3 第 4 条）。对 T1（只看频率）影响小，对 T4 和带宽有影响。
5. 「事先固定的非默认值」是 002-A 没有明文覆盖的情形，提案 005 还在等人决定。如果人选了 005 的方案 B（成对冷启动），本实验的结论还要与冷启动对照一起看。
