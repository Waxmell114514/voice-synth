## 2. 声门下管模型

### 2.1 离散化

与口腔同段长 Δ = L/N（≈0.33 cm），每段单向 1 采样（仿真率不变）。声门下总长 ~19 cm → **约 58 段**，而不是 Planner 设想的 10–15 段。两种实现（声学上等价）：
- a. 58 个普通 KL 段（计算量约 +130%，最简单）；
- b. **12–15 个"变截面结点"+ 各结点之间的均匀延迟线**（一个 m 采样延迟线 = m 个面积相同的段，无散射，只需环形缓冲区）。这样满足"10–15 段"的计算量，且结果与 a 逐样本相同（损耗按每采样 g^1 对每个存储样本施加，或在每段延迟线出口一次乘 g^m，二者能量上等价但 zero_input_energy 的逐采样曲线不同——推荐前者）。

### 2.2 默认面积剖面（声门→远端）

本规格用刚性管传输线（每 cm 衰减 5×10⁻⁴ Np，远端压力反射 r_d）在网格上拟合女性 Sg（§1.1）得到【推导；拟合由 Researcher 在草稿中计算，Implementer 须用引擎复算】：

| 段 | 长度 | 面积 |
|---|---|---|
| 声门下锥 | 1.5 cm（≈5 段） | 1.0 cm² |
| 气管 | 9 cm（≈27 段） | 2.0 cm² |
| 支气管树等效喇叭 | 9 cm（≈27 段） | 2.0 → 16 cm²，指数增长 A(x) = 2.0·8^{x/9cm} |
| 远端 | | 压力反射 r_d = −0.6 |

计算结果：Sg1/Sg2/Sg3 = 644 / 1570 / 2394 Hz（目标 660/1513/2426，均方根相对误差 2.7%）。附近的其他可行解：锥段 1.0 cm×0.8 cm²、气管 9 cm×1.2 cm²、喇叭到 8 cm² → 640/1568/2426 Hz。**结论：Sg1 偏低的问题可以靠远端喇叭形扩张部分补偿，不必建非刚性壁**；但剖面是"等效声学"剖面，不是解剖测量值【未核实】。

### 2.3 远端终端

- 一般形式：远端压力反射 b_new = r_d · f_end，|r_d| ≤ 1。
- r_d = 0：完全吸收（匹配阻抗，等价于无限长均匀管）。仅有吸收终端时共振只来自截面变化，较弱。
- r_d → −1：理想开口（Hanna 2018 与 Lulich 2011 的简化模型用带法兰的开口圆柱）【已核实 S2】。
- 默认 −0.6（部分开口 + 损耗的集总），范围 [−0.95, 0]。肺泡终端阻抗可不考虑【已核实 S2，见 §1.2】。

### 2.4 声门下损耗

Hanna 等在全部计算中把衰减系数设为光滑刚性圆柱黏热值的 5 倍【已核实 S2】。g001-e04 若已实现，可直接套用（面积用声门下各段面积）；否则用单独的常数 `sub_wall_loss`（默认取声道 wall_loss 的 2 倍，【未核实】）。Sg 的带宽数据我未找到可核实来源【未核实】。

## 3. 声门二端口结点（耦合公式）

符号（kl.py 的相对单位，Z = 1/A，ρc 已约掉；e02 中的 Zg 除以 ρc 得 z_g，单位 cm⁻²）：
- 声道第 1 段：Z_t = 1/A_1，入射（从唇方向来的）波 b = b[0]，出射 f_new[0]；
- 声门下顶段：Z_s = 1/A_s1，入射（从肺方向上来的）波 a，出射（向下）a_out；
- 声门：短路流量 u_sc = LF 流量 ug（含送气噪声），内阻 z_g(t)，电导 g_g = 1/z_g。

连续性：p_s − p_t = z_g·(U − u_sc)（Norton，U 为流向声道的体积速度）。解得【推导】：

**U = ( 2 g_g (a − b) + u_sc ) / ( 1 + g_g (Z_s + Z_t) )**
**f_new[0] = b + Z_t · U**
**a_out = a − Z_s · U**

检查：
1. 闭相 g_g = 0 ⇒ U = u_sc：声道得 f = b + Z_t u_sc（与 g0 完全相同），声门下得 a_out = a − Z_s u_sc（流量从气管抽出，激励声门下管，符号相反，物理正确），两侧都是闭端全反射【推导】。
2. Z_s → 0 且 a = 0（声门下为理想压力源）⇒ f_new = r_g b + Z_t (1+r_g)/2 · u_sc，r_g = (z_g − Z_t)/(z_g + Z_t)，**恰为 e02 的公式**【推导】。所以 e05 是 e02 的推广，二者共用 Ag(t)、Zg(t) 代码。
3. 声门下 DC 压力 Ps 只进入 Zg（e02 §2.3），声学管只传扰动量。

用电导形式计算，g_g ∈ [0, ∞)，无除零。

## 5. 对 T0 与能量检验的影响，实现注意

### 5.1 T0 均匀管
钩子要求声门全闭 ⇒ g_g ≡ 0 ⇒ 声道一侧 f_new[0] = b + Z_t·u_sc，与 g0 逐样本相同；声门下管与声道**完全解耦**（只有 u_sc 从声门下抽流，T0 只读唇端）。**不改变 T0 结果**。最简做法：T0 钩子传 sub_enable=0 或 g_g≡0（走同一结点代码）。

### 5.2 零输入能量
- 能量须把声门下各段（或延迟线中每个存储样本）按面积加权计入：E = Σ_tract A(f²+b²) + Σ_sub A(f²+b²) + 鼻腔。
- 结点功率平衡（u_sc=0 时）：入射功率 − 出射功率 = z_g·U² ≥ 0（在相对单位下乘以对应权重）【推导】，加上 |r_d| ≤ 1、损耗 g ≤ 1 ⇒ 逐采样单调不增。
- 零输入时 g_g 用 Ag_min 计算的常数（与 e02 §5.2 相同）；Ag_min=0 时两管解耦，各自单调。
- 能量权重：kl.py 的 E = ΣA(f²+b²) 对应真实功率 Σ A p²/(ρc)，两管 ρc 相同，可直接相加【推导】。

### 5.3 风险
1. **静态反射叠加的计算量**：58 段使内核耗时约翻倍；用 §2.1 b 方案。
2. **共振峰"捕获"**：Sg2 ≈ 1513 Hz 与 /a/ /e/ 的目标 F2（1605/1503，见 gen_001_plan.json）重合，开相耦合会在 Sg2 附近产生极零对，可能使 F2 测量偏移（方向不定，Planner 已标为探索性）。
3. **Ag_max 大时耦合强**：Hanna 2016 转引 Fant 1972，声门有效半径 > 1.4 mm（Ag ≳ 0.06 cm²）时声门下特征才明显出现在唇端阻抗谱里【已核实，见 e02 S3】。效果大小主要由 glottal_area_max 控制，须与 e02 一起优化。
4. **不要用时变惯性**（同 e02 §5.3.1）。
5. 送气段/清音若以后让声门外展（Ag 很大），声门下共振会明显出现在送气噪声谱中（Fant 等 1972 的观点，经 S2 转引），这是预期现象。
6. 远端 r_d 若被优化到 −0.95 附近，Sg 带宽变很窄，开相会产生可闻的"嗡"声；schema 上限建议 −0.95 已足够保守。
