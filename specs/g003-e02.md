## 0. 结论摘要

1. **带宽求法选「单步状态转移矩阵的特征值」**（方法 A，§2）：用引擎的 `kl_run` 跑 1 个采样，把每个单位状态向量的响应拼成矩阵 M，特征值 z 直接给出 F = ∠z·fs_sim/2π、B = −fs_sim·ln|z|/π。结果是精确的，不需要拟合，也没有阶数选择。对冲激响应做 2N 阶协方差 LPC（方法 B）作交叉校验，两者在草稿中相差 < 0.01 Hz。从合成音频求带宽（方法 C）误差太大，不用来求带宽，只用来求倾斜量。
2. **解析校验**（§3）：只要两端理想反射（|r_g| = |r_lip| = 1）、损耗为均匀的 μ，**任意面积函数**（不只是均匀管）的所有极点半径都恰好等于 1 − μ，所以 B = −fs_sim·ln(1−μ)/π。fs_sim = N·c/L，所以「328 Hz」只在 L ≈ 15.0 cm 时成立：L = 15.0 cm 时为 328.44 Hz，L = 17.5 cm 时为 281.52 Hz。工具自检要同时测两种长度。
3. **倾斜量**（§4）：H1−H2、H1−A1、A1−A3（附 H1−A3）在合成孤立元音上测量，40 ms 窗，不预加重。同时输出原始值，以及用方法 A 的精确 F、B 按 Iseli–Alwan 公式校正后的值。另加一个解析校验：只有声源时，H1−H2 应等于 Fant 1995 式 (8) 给出的 −7.6 + 11.1·Rd dB。
4. **草稿预算**（§6）：我已用 e06 参数和引擎的 kl_run 算过，6 个元音的 B1–B3 都在 328–338 Hz，B3/B1 在 0.975–1.011。这条机制预测**由线性代数保证成立**（§3.2），不能算作检验。真正有信息量的只有 wall_loss 敏感性扫描对 T1 的影响（§5）。

## 2. 从 KL 求极点和带宽（spec_request 2）

### 2.1 三种做法

| 方法 | 做法 | 优点 | 缺点 | 草稿实测（e06 参数，/a/ /i/ /u/） |
|---|---|---|---|---|
| **A. 状态转移矩阵特征值**（采用） | 静态面积、零输入下，`kl_run` 是线性时不变映射 x_{t+1} = M·x_t，x = (f[0..N−1], b[0..N−1]，若有辐射再加 w)。从每个单位向量 e_j 出发跑 `kl_run(n=1, block=1, …)`，得到 M 的第 j 列。eig(M) 就是传递函数的全部极点 | 精确，没有窗、阶数、拟合；直接用引擎内核，任何终端（r_g、r_lip、μ、κ_rad、κ_bl）都自动包含在内 | 只给极点，不给零点和幅度；只适用于静态面积 | 与方法 B 差 < 0.01 Hz【推导】 |
| B. 冲激响应 + 协方差 LPC | 声门注入单位冲激，在 fs_sim 下取唇端体积速度 u_lip（去掉 N 个采样的纯延迟），做 p = 2N 阶协方差法 LPC，求根 | 可以同时得到 |H(f)|，用于画谱、求零点（g003-e06 的梨状窝零点需要） | 有鼻腔或辐射时阶数要改，p 选错会出现伪极点 | /a/ F 1022.9、1582.9、2618.3 Hz，B 331.80、329.51、328.89 Hz，与 A 相同【推导】 |
| C. 合成音频 LPC | 合成孤立元音，22.05 kHz，中段 60 ms，预加重 0.97，Hamming 窗，自相关法 24 阶 | 测的是最终输出 | 声源谐波与 F1 互相干扰，又有伪极点 | /i/ B1 157 Hz（A 给 330）；/a/ B1 445（A 给 332），在 1.3–1.5 kHz 多出 B > 1500 的伪极点【推导】 |

**选 A**。B 作为每次运行的交叉校验：两者的 F1–F3、B1–B3 相差超过 0.5% 时，报错退出。C 不用于带宽，只用于 §4 的倾斜量。

### 2.2 B = −fs·ln|z|/π 与 −3 dB 宽度的误差

- 冲激不变映射 z = e^{sT}：s = −πB ± j2πF 对应 |z| = e^{−πB/fs}，所以 B = −fs·ln|z|/π 是**按衰减率定义的带宽**，对离散系统本身是恒等式，没有近似误差【推导】。用 1 − |z| 代替 −ln|z| 时，相对误差约为 πB/(2fs)：B = 330 Hz、fs = 102 kHz 时为 0.5%【推导】。
- −3 dB 宽度只在 B ≪ F、且共振峰之间相距很远时才等于 B。本引擎的 B ≈ 330 Hz，F1 只有 250–350 Hz（i、u、ü），与共轭极点、相邻共振峰都会互相影响。草稿实测（e06 参数，|U(f)|，2¹⁸ 点 FFT）：/i/ F1 的 −3 dB 宽度为 398 Hz（极点给 330，+21%），峰位 243 Hz（极点 286）；/u/ F1 宽度 468 Hz（+39%）；/a/ F1、/a/ F2、/i/ F2、/u/ F2 两侧下降不到 3 dB，宽度无定义【推导】。所以不用 −3 dB 宽度。
- fs_sim 取 `sim_rate(L, N, 22050)` 的返回值（引擎重采样用的有理近似值），不用理想值 N·c/L。两者相对差 6×10⁻⁶（L = 15.04 cm 时为 102418.03 Hz 与 102417.39 Hz）【推导】，取引擎的值是为了让 F 与输出音频的频率一致。

### 2.3 工具对参数文件的处理

- 参数用 `engine.params_io.load_params` 读，缺省值由它补。面积取 `max(area_v, min_area)`（与 `zero_input_energy` 一致）。
- 软腭关闭（Avp = 0）。这时内核把鼻腔第 0 段清零，鼻腔 k = 0 结点对鼻腔侧刚性反射，口腔子系统闭合【推导：读了 kl.py】，所以状态向量里不放鼻腔。
- 终端：r_glottis、r_lip、wall_loss 取参数文件的值；若引擎树的 schema 里有 `rad_kappa`、`bl_loss_kappa`，同样取参数值。
- **签名适配**：各分支的 `kl_run` 参数不同。main 的最后一个参数是 want_energy；g002-e04 多了 rad_kappa、length_cm、w；g002-e03 多了 kappa_bl、dx_cm【推导：读了三棵树的 kl.py】。工具用 `inspect.signature(kl_run.py_func)` 读参数名，按名字填值。遇到不认识的参数名就报错退出，**不猜默认值**。
- 引擎树：`--root <树>`，默认是当前仓库，做法照搬 `tools/dynamic_t0_check.py` 的 `--parent-root`（清掉 `sys.modules` 中的 engine.* 再导入）。这样同一个工具可以测 e04、e03 的 worktree。

- `--override k=v`：在内存中改某个标量（例如 wall_loss = 0.002），不写文件，用于 §5 的扫描。

## 3. 解析校验（spec_request 4）

### 3.1 定理
设 M₀ 为 μ = 0 时的单步矩阵。kl.py 的损耗步对所有行波乘同一个 g = 1 − μ，所以 M = g·M₀，特征值为 g·λ(M₀)【推导：读了 kl.py，损耗步对 f、b 统一乘 g】。
- 能量 E = Σ A_k(f_k² + b_k²) 是正定二次型。|r_g|、|r_lip| ≤ 1 时，E 在 M₀ 下不增，所以 |λ(M₀)| ≤ 1。两端都是 |r| = 1 时，E 守恒（结点功率守恒，见 specs/g0-seed.md S6），|λ(M₀)| = 1【推导】。
- 由此可得：
  - 两端理想反射时，**任意面积函数**的每个极点都有 |z| = 1 − μ，B = −fs_sim·ln(1−μ)/π，与频率、元音无关。
  - 一般情况（|r| ≤ 1）下，**B ≥ −fs_sim·ln(1−μ)/π 对每个极点都成立**，这是下限。

### 3.2 自检用例（`--selftest`，每次运行前跑一次，任一失败就退出）

## 4. H1−H2、H1−A1、A1−A3 的定义与校正（spec_request 3）

### 4.1 定义
- H1、H2：第 1、2 谐波的幅度（dB）。H1−H2 反映开商，应在非高元音上测，以免 F1 抬高 H1 或 H2【已核实 B5，二手（Stevens 等 2005 讲义，引 Hanson 1997）】。
- H1−A1：A1 是 F1 区内最强谐波的幅度。H1−A1 近似反映 B1，值越大 B1 越宽；同样应在非高元音上测【已核实 B5，二手】。
- H1−A3：A3 是 F3 附近谐波峰的幅度，反映频谱倾斜【已核实 B5，二手】。
- A1−A3：spec_request 要求的量，A1、A3 定义同上。H1−A3 也一并输出。
- 讲义的测量设置：40 ms 窗，**不预加重**；每个元音中段每隔 20 ms 测 3–4 次，取平均【已核实 B5】。
- Hanson 1997 原文（JASA 101:466–481）没读到：MIT DSpace 上的博士论文 PDF 返回 429（防火墙），JASA 原文没有开放获取【找不到】。所以 Hanson 对 A3 的具体校正式、她的女声均值，**本规格都不给数值**。

### 4.2 校正公式
- Hanson 的 F1 校正：H* = H − 20·log10(F1²/(F1² − f²))，f 取 F0 或 2F0，要求 f 比 F1 至少低 100 Hz【未核实：只见 Iseli & Alwan 2004 的检索摘要转述】。
- Fant 1995 式 (10)：每个共振峰对频率 f 的增益为 G(f, F) = −20·log10(1 − f²/F²) dB。式 (11) 带带宽：G(f, F, B) = −10·log10[(1 − f²/F²)² + (f·B/F²)²] dB。原文说 F1 接近 F0、2F0 时需要用带 B 的形式【已核实 B4】。
- Iseli & Alwan 2004（本工具采用，在采样率 fs = 22050 Hz 下离散化）：
```
r_i = exp(−π B_i / fs),   ω_i = 2π F_i / fs,   ω = 2π f / fs
corr_i(f) = 20·log10(1 + r_i² − 2 r_i cos ω_i) − 10·log10(1 + r_i² − 2 r_i cos(ω_i + ω)) − 10·log10(1 + r_i² − 2 r_i cos(ω_i − ω))
H*(f) = H(f) − Σ_i corr_i(f)
```
【二手（代码）：opensauce-python `correction_iseli_i`，docstring 引 Iseli & Alwan，ICASSP 2004】
- 本工具的优势：F_i、B_i 不用估计，直接用方法 A 的精确值。所以校正项只剩「5 kHz 以上的高阶极点」和「输出一阶差分」两类误差。
- 校正范围：H1*、H2* 校正 F1–F4。A1* 校正 F2–F4（A1 是 F1 本身的峰，不扣 F1）。A3* 校正 F1、F2、F4（不扣 F3）。这是我照「去掉其他共振峰对该谐波的抬升」的思路定的【推导】，Hanson 的原式没核实。
- 输出：原始值（H1−H2、H1−A1、A1−A3、H1−A3）和校正值（H1*−H2*、H1*−A1*、A1*−A3*、H1*−A3*）都列。i、u、ü 的 F1 < 2F0 + 100 Hz 时，加标记 `"high_vowel_caveat": true`。

### 4.3 音频测量细节
- 音节：a1、o1、e1、yi1、wu1、yu1（零声母、一声，基频平稳）。用 `engine.synth.render([tok], P, seed=0)`。和 T1 的音节、声调是否相同，我没查（不读 eval/），这里只要求孤立元音可比。
- 窗：有声段（|y| > 0.02·max）的中点，前后 −20、0、+20 ms 各取一个 40 ms Hamming 窗（窗型是我的选择，讲义没规定），不预加重，补零到 2¹⁶ 点。
- F0：40 ms 段的自相关峰，限 100–500 Hz，再用 H1 峰的抛物线插值修正。
- 谐波幅度：在 k·F0 ± 0.2·F0 内取最大值，抛物线插值，单位 dB。A1：|k·F0 − F1| ≤ F0 的谐波中取最大；A3 同理，用 F3。F1、F3 取方法 A 的结果。
- 结果取 3 个窗的平均。

### 4.4 倾斜量的解析校验（加入 `--selftest`）
- Fant 1995 式 (8)：**在声门气流导数谱上，H1−H2 = −7.6 + 11.1·Rd（dB）**【已核实 B4】。本引擎的输出是 y = diff(u_lip)，其中 u_lip = 声道 * cumsum(du)，所以 y ≈ 声道 * du，也就是声道作用在气流导数上【推导：读了 synth.py】。
- 用例 7：只取声源。`engine.source.lf.glottal_source` 在固定 F0 = 220 Hz、jitter = shimmer = 0 下生成 du，Rd 取 0.5、1.1（e06 的 rd_modal）、2.0，分别测 H1−H2，与式 (8) 比较。期望值分别为 −2.05、4.61、14.6 dB；容差 ±1 dB，是我的估计（Fant 只说线性「几乎完美」，没给 Rd 式的误差）【推导／估计】。
- 用例 8：e06 的 /a/ 整段合成音频，H1*−H2* 与用例 7 的 Rd = 1.1 值相差 < 1.5 dB（估计），用来检验 §4.2 的校正代码。

## 7. 对假设的意见

1. **机制预测不是检验**。按 §3.1，wall_loss = 0.01 时每个极点都有 B ≥ 327.6 Hz，所以「e06 的 B1 < 200 Hz」这个证伪条件在数学上不可能出现。B3/B1 > 1.5 也几乎不可能：r_lip = 0.995 对均匀管只加 1.86 Hz【推导】。§6 的草稿已经给出结果。这一条应改写为工具的正确性检查，不要计入预测命中。
2. **唯一可证伪的部分是 S1**：wall_loss = 0.002 时 T1 是否比 0.01 时差 ≥ 0.004。这才是在检验「贴上限是为了宽带宽」。注意：即使 T1 变差，也可能是 eval 的共振峰估计器在窄带宽时锁到 F0 谐波上（g002-e03 规格 §1.3 第 3 条的猜测），即「宽带宽是为了骗过测量」，而不是「宽带宽本身更像真人」。S1 区分不了这两种解释。
3. r_lip、r_glottis 贴上限与 wall_loss 贴上限「是同一件事」，这一点得到 §3.1 的支持：端点反射引入的损耗只有几 Hz，带宽几乎全部来自 μ。
