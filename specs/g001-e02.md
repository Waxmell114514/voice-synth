# g001-e02 规格：随 LF 周期变化的声门端反射 r_g(t)（开相声源-声道耦合）

父代：g000-e00。改动模块：source（导出声门面积波形）、tract（声门端边界）。
目标音色：成年女性。核实标记沿用 specs/g0-seed.md：
- 【已核实 Sx】：我实际读到了来源 Sx 中的该公式/数字（来源表见文末）。
- 【推导】：由已核实公式做的代数推导或单位换算。
- 【未核实】：凭记忆或仅见二手转述，schema 取值范围须放宽。

## 1. 物理图景

现在的声门端：`nf[0] = r_glottis·b[0] + ug/A1`，r_glottis 为常数（默认 0.85），ug 为 LF 积分出的体积速度（相对单位），即"理想流源 + 固定损耗"。

真实声门是一个随时间变化的阻抗 Zg(t)：闭相 Ag≈0 → Zg→∞（全反射，r_g→+1）；开相 Ag 大 → Zg 与第 1 段特性阻抗 Z1 = ρc/A1 同量级，r_g 下降甚至变负，声道能量经声门流失（B1 变宽），且低 F1 的高元音 F1 上移。

文献量级（用于核对实现，不是拟合目标）：

|---|---|---|

## 2. 声门阻抗

### 2.1 准静态压降（单质量 / 均匀声门）

ΔP = Ps − p_1 = k_g · ρ U² / (2 Ag²) + R_v·U，　R_v = 12 μ d l_g² / Ag³

- 来源形式：Fulcher, Scherer & Powell 2013 Eq.1：ΔP_tr = (k_ent − k_ex)·ρU_g²/(2 l_g² w²) + 12μΔx/(l_g w³)·U_g，其中 w 为声门宽度（原文记作 d），Δx 为声门轴向厚度。代入 Ag = l_g·w 即得上式（R_v 中的 d 即 Δx）。【公式已核实 S1；Ag 代换为【推导】】
- k_g = k_ent − k_ex。Ishizaka-Flanagan 型模型常用 k_ent = 1.37，Fulcher 2012 取 k_ex = 0【已核实 S2】。IF 1972 原文的具体系数（入口 0.37、出口恢复项）我没读到原文【未核实】。
- 惯性项（Ishizaka & Flanagan 1972 有 L_g = ρd/Ag）：【未核实】（IF 1972 原文 p.1241 的公式在我读到的网页中只是图片，见 S5）。本假设**不实现**惯性项，理由见 §5.3。

### 2.2 对声学扰动的线性化（微分电阻）

对平均流叠加的小声学扰动，声门呈现的是微分电阻：
Zg = ∂ΔP/∂U = k_g ρ |U| / Ag² + R_v　【推导，由 2.1 求导】
（大信号电阻 ΔP/U 的动能部分只有它的一半；用于反射系数时应取微分形式。Fant 1982 / Ananthapadmanabha & Fant 1982 的线性化声门电阻我没读到原文，不能确认他们采用哪种形式【未核实】；S4 只核实了题录。）

### 2.3 由 LF 流量导出声门面积

引擎里的 ug 是相对单位，不能直接用 Bernoulli 由流量求面积，故采用"面积正比于 LF 流量形状"：

1. 每个周期内归一化流量 ũ(t) = U_LF(t)/max_周期 U_LF ∈ [0, 1]（LF 一周期净流量为零且起止为 0，见 g0-seed.md §1.1）。
2. Ag(t) = Ag_min + (Ag_max − Ag_min)·ũ(t)^γ　（γ 默认 1）【做法为本规格的设计选择，未见文献逐字给出 → 未核实】
3. 绝对流量用开相 Bernoulli 估计（忽略声道压力）：U_abs(t) = (Ag(t) − Ag_min)·√(2Ps/(k_g ρ)) + U_leak，U_leak = Ag_min·√(2Ps/(k_g ρ))，即 U_abs = Ag·√(2Ps/(k_gρ))【推导】
4. 代入 2.2，动能部分化简为与面积成反比的闭式：
   **Zg(t) = √(2 k_g ρ Ps) / Ag(t) + 12 μ d l_g² / Ag(t)³**　【推导】
5. 不发声（f0≤0 或 voice 幅度≈0）时 Ag = Ag_min（若想在清音/送气段模拟外展，用 Ag_abd 参数，留给后续假设）。

数量级（ρ=1.14×10⁻³ g/cm³，Ps=8 cmH₂O=7845 dyn/cm²，k_g=1.37，μ=1.86×10⁻⁴ P，d=0.3 cm，l_g=1.0 cm）【推导；μ、d、l_g 未核实】：
| Ag (cm²) | 动能项 (dyn·s/cm⁵) | R_v | Zg | 对 A1=0.56 cm²（Z1=71）的 r_g |
|---|---|---|---|---|
| 0.15 | 33 | 0.2 | 33 | −0.36 |
| 0.10 | 49.5 | 0.7 | 50 | −0.17 |
| 0.05 | 99 | 5.4 | 104 | +0.19 |
| 0.02 | 248 | 84 | 332 | +0.65 |
| 0.005 | 990 | 5360 | 6350 | +0.98 |

结论：开相峰值附近 r_g 可降到 0 附近甚至为负，这比 g0 的常数 0.85 强得多；闭相（Ag≈Ag_min 很小）r_g→1。**g0 的 r_glottis=0.85 实际上把开相损耗平摊到了整个周期，改为 r_g(t) 后闭相损耗消失，wall_loss 等须重新调**。

## 3. 阻抗 → 压力波反射系数，以及注入项

第 1 段特性阻抗 Z1 = ρc/A1（R_k = ρc/A_k 已在 g0 规格核实）。在第 1 段声门端，p = p⁺ + p⁻，U = (p⁺ − p⁻)/Z1。把声门看作 Norton 等效：短路流量 u_sc（就是 LF 流量 ug）并联内阻 Zg，U = u_sc − p/Zg。解得【推导】：

- **r_g(t) = (Zg − Z1)/(Zg + Z1) = (1 − G̃) / (1 + G̃)，G̃ = Z1/Zg = Z1·Gg**（用电导 Gg=1/Zg 计算，Ag→0 时 Gg→0，避免除以无穷）
- **p⁺_1 = r_g(t)·p⁻_1 + Z1·(1 + r_g(t))/2 · u_sc(t)**

对应到 kl.py 的相对单位（Z1 ↔ 1/A1，ρc 已约掉）：
`nf[0] = r_g[t]·b[0] + 0.5·(1 + r_g[t])·ug[t]/A[blk,0]`，
其中 r_g 只依赖无量纲比 G̃ = (ρc/A1)/Zg，Zg 用 cgs 绝对单位（dyn·s/cm⁵），ρc = 1.14×10⁻³ × 35000 = 39.9 g/(cm²·s)【推导；ρ、c 未核实，见 g0 规格】。

检查：Zg→∞ ⇒ r_g=1、注入项 = ug/A1，与 g0 完全一致【推导】。

**注意**：不能沿用 `ug/A1` 的注入而只把 r_g 改成时变——那等于把 Norton 内阻算了两次（开相会凭空多注入能量/幅度）。必须同时乘 (1+r_g)/2。

A1 取当前控制块的 A[blk,0]（已经过 min_area 钳位）；若面积随块变化，r_g 每采样重算（便宜：一次除法）。

## 5. 对 T0 与能量检验的影响，实现注意

### 5.1 T0 均匀管（tube_impulse_response）
钩子必须声门全闭：传 r_g ≡ 1（等价 Ag ≡ 0、Gg=0），注入因子 (1+r_g)/2 = 1 → 与现在逐样本完全相同。**不改变 T0 结果**。建议 kl_run 改为接收 r_g[n] 数组（或 Gg[n]），T0 传全 1，synth 传计算值，这样仍走同一内核（Critic 要求）。

### 5.2 零输入能量（zero_input_energy）
- 声门端为无记忆边界，任何 |r_g(t)| ≤ 1 的序列（含时变、含负值）都使边界处入射能量 ≥ 反射能量，**逐采样单调不增仍然成立**【推导】：边界吸收功率 ∝ (1 − r_g²)·(p⁻)² ≥ 0。
- 零输入时没有 LF 周期，建议钩子用 Ag = Ag_min 算出的常数 r_g（物理上"声带静止"），或为了覆盖时变路径传默认参数下一个周期的 r_g(t) 循环序列——两者都单调。T0 的 min/max 角点：Ag_min=0 时 r_g=1（无损边界，能量仍不增）。
- 必须保证数值上 r_g ∈ [−1, 1]：G̃ ≥ 0 时公式自动满足；Gg 由 Zg 取倒数，Zg 两项均为正，Ag 下限钳在 ≥ 1e-6 cm² 再算。

### 5.3 稳定性与能量风险
1. **不要加时变惯性 L_g(t)=ρd/Ag(t)**：时变电感在 Ag 增大（L 减小）时按 Φ²/(2L) 释放能量，是参量泵浦，可能破坏单调性；本假设只用纯电阻 Zg（无记忆）。惯性项如需要，另立假设并单独检验。
2. 微分电阻 2.2 在 U 与 Ag 同时→0 时由黏滞项主导，不会出现 0/0；Ag_min=0 且 ũ=0 时直接置 Gg=0。
3. r_g 在开相可能为负且变化快（每周期从 ~+1 到 ~−0.3 再回来），会对 F1 带宽产生周期调制，这是预期效果，不是 bug；但若 r_g 的跳变与 LF 回复相不同步会产生咔哒声：Ag(t) 必须由同一周期的 U_LF 导出（同一 jitter/shimmer 实现后的周期长度）。
4. 送气噪声 aspn 目前加在 ug 上，同样乘 (1+r_g)/2 注入。
5. 输出幅度会因开相注入因子 < 1 而下降，finalize 会重新归一，无需额外处理。
6. 本假设与 e05（声门下声道）共用 Zg(t)；若 e05 同时启用，声门端改用 e05 的二端口结（e05 §3），本节公式是其 Z_sub→0（理想压力源）的极限。

### 5.4 预期效果的自检
用 /i/ 面积函数、F0=220 Hz、默认参数，比较 e02 开/关的长时平均谱：F1 应上移若干 %（量级参考 §1，[i] [y] 可 > 10%），B1 明显变宽。若 F1 下移或谱峰变尖，检查注入因子和 r_g 符号。
